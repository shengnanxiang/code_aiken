## 0. 一页纸执行摘要

**要干的事**：把"弹出式氙气闪光灯"从调研结论变成可量产的供应商交付物。路径 = **双轨采购**（灯管走标准件 + 模组集成走定制），分四个阶段推进，每阶段有明确通过标准与不过的应对。

## 1. 方案定义：弹出式氙灯总成是什么

### 1.1 构成

```
氙灯总成 = 灯管（氙气管，GN10 级直管/U管）
         + 反光罩 + 灯罩透镜（注塑件）
         + 升压电路（AA 3V → 300V）
         + 储能电容（330V / 120-160μF）
         + 触发线圈（次级 2-6kV 脉冲电离氙气）
         + 弹出机构（垂直顶出式：机械开关触发 + 弹簧顶出 + 到位锁定）
         + 充电指示灯（氛泡或 LED）
```

### 1.2 规格目标

| 参数 | 目标值 | 依据 |
|---|---|---|
| 闪光指数 GN | 10-15（ISO100·米） | 相机内置闪光灯主流档位；一次性相机 GN≈10-12 同级 [M] |
| 回电时间 | 3-8s（AA 碱性）/ 2-5s（镍氢） | 一次性相机典型值 [H]；神牛 TT350 0.1-2.2s 为 GN36 大电容参照 |
| 闪光寿命 | ≥5 万次 | 直管氙气管规格表标称 50,000 次 [H]（山东电建规格表）；按日拍 20 张×3 年≈2.2 万次，余量 2 倍+ |
| 闪光色温 | ≈5500-6000K（日光白） | 氙气闪光灯固有特性 [H] |
| 供电 | 2×AA 专供（与主锂电隔离，架构 B） | 已裁决 |
| 结构 | 弹出式（垂直顶出，Yashica 35MF 式：灯体平时完全缩于机身顶部仓位内、外观平齐不可见，机械开关触发后向上直线弹出），含充电指示灯 | 硬件定义冻结（2026-11-04 产品负责人指定垂直顶出方向） |

### 1.3 与产品定义的关系（为什么值得做）

氙灯是 Bromo「机械仪式感」叙事的核心一环，对应三重体验链：
1. **弹出**——拨动机械开关，灯体从平齐的机身顶部"咔"地垂直升起（Yashica 35MF 式顶出的惊喜感：平时完全不可见，动作瞬间"长出来"）；
2. **充电**——氖灯/LED 缓缓亮起，"充电等待"本身是仪式（UX 文案已定位为卖点而非缺点）；
3. **闪光**——氙气的凝固感（1/1000s 级闪光持续时间）与肤色质感是 LED 补光（GN3-6 级）无法等效的 [M]。

战略意图文档已把氙灯列入"新学费项"（ACCEPT 层）：氙灯模组整合是研发未走过的路，NRE 与周期风险集中在这一段——**本方案的存在意义就是把这段新学费花得可控、可验证、可回退**。

## 2. 技术方案

### 2.1 电路拓扑（为什么 AA 能点亮氙灯）

```
2×AA (3V) → 自激振荡升压变压器 → 300V → 储能电容(120-160μF/330V)
                                                        ↓
快门同步信号 → 触发线圈(次级 2-6kV 高压脉冲) → 氙气管电离导通 → 电容瞬间放电 → 闪光
                                                        ↓
                              充电指示（氛泡/LED 检测电容电压）→ 就绪提示
```

**两个量产先例证明此拓扑成熟**：
- **一次性胶片相机**：1 节 AA 1.5V 驱动 GN10 氙闪 + 充电指示灯，全球年销千万支级，量产验证 30+ 年 [H]——Bromo 用 2×AA，电压裕量更宽；
- **神牛 TT350 机顶闪光灯**：2 节 AA 镍氢驱动 GN36（远超 Bromo 需求的 GN10-15）、全功率 210 次、回电 0.1-2.2s [H]——证明 2×AA 驱动更强氙灯都可行。

**工程要点**（给工程对接者）：
- 触发控制 IC + 高压开关管（IGBT/MOS）走标准器件（驱动电路 BOM ¥3-5 [M]）；
- **电池建议**：明示推荐镍氢（佳能/索尼/尼康均有"闪光灯禁用 AA 锂电池"安全公告 [H]——锂 AA 内阻特性差异有过热风险）；碱性可用但回电偏慢（3-8s）；
- **高压防护**：300V 节点需结构防护 + 泄放电阻（关机后电容放电），一次性相机时代有成熟做法 [H]。

### 2.2 弹出结构原理（垂直顶出式，2026-11-04 方向修正）

- **结构**：灯体（灯管+反光罩+灯罩透镜+升压/储能电路板）作为一个滑块组件，平时完全收纳在机身顶部仓位内（外观平齐，不可见）→ 操作机械开关 → 锁定机构脱开 → 弹簧驱动灯体沿导轨向上直线顶出（telescoping/顶针式，非旋转）→ 到位卡扣锁定（"咔"声来自锁定卡扣）→ 回压灯体即压缩弹簧重新收纳并锁定；
- **结构参照**：Yashica 35MF（产品负责人指定，参照图已归档 bromo/ref/yashica-35mf-flash-popup.jpg）——该机为 1970 年代旁轴机，其闪光灯采用"藏于顶盖内、开关触发后垂直弹出"的机构 [M]（产品负责人文字定义为权威口径；该机型公网维修资料稀少，机构细节以归档参照图与文字定义为准，公网佐证待阶段 1 补充维修手册/拆解资料）。通用工程原理佐证：垂直顶出（弹簧+导轨+卡扣锁定+按压回纳）是成熟的标准机构模式，广泛用于 SD 卡槽、SIM 卡托、ABS 弹起钥匙扣等消费产品 [H]——组成元素全部货架化；
- **无现成公模**：现役产品中没有可直接套用的垂直顶出氙灯模组（Instax 的灯是常开的），需要小定制——这正是 NRE ¥3-10 万 [L] 的来源（模具 + 治具，周期 30-45 天）。

**两种弹出结构的工程对比（保留供工程/ODM 参考）**：

| 维度 | 垂直顶出式（现方案，Yashica 35MF 类） | 旋转弹起式（原方案，Nikon 军舰头/柯达 KB32 类） |
|---|---|---|
| 机构原理 | 弹簧+导轨+卡扣锁定+按压回纳（直线运动） | 弹簧+旋转支点+限位（旋转运动） |
| 仓体空间需求 | **灯体全高必须藏于机身内**——顶部需预留灯体弹出高度（估 8-12mm [L]）+ 弹簧压缩空间，**占用机身顶部内部堆叠空间最大**；收纳态外观平齐（不可见）是设计卖点 | 灯体立起后靠旋转支点外翻，收纳时平贴机身顶面，内部堆叠占用较小，但顶面始终可见灯体轮廓 |
| 与顶部堆叠的关系（联动 vf-odm 报告 §3.2 顶部堆叠风险提示） | **需重新审视**：Bromo 顶部已有弹出氙灯仓位+AA 仓+取景器+拨杆，顶出式仓位向下侵入机身内部（与主锂电/主板/取景器光路的竖向空间竞争），整机结构布局需在 EVT 前做堆叠专项评审——**这是垂直顶出方向新增的首要工程风险点**（详见 §5 X2） | 灯体主要占用顶面以上空间，内部侵入浅 |
| 弹出行程 | 直线上下，行程 = 灯体高度（估 8-12mm [L]） | 旋转 60-90°，行程由支点位置决定 |
| 防误触发设计 | 开关触发+双段锁定（弹出到位锁定/收纳到位锁定）；顶部平齐无外凸件，包内携带无钩挂风险——**防误触发与耐携带性天然更优** | 按键释放后灯体立即弹起；收纳态灯体贴附顶面，挤压力可能意外触发 |
| 手感调校点 | 开关触发力、弹出速度（弹簧刚度+导轨阻尼）、到位"咔"声、回压收纳力 | 按键行程、弹起力度、限位声响 |
| 密封/防尘 | 仓位开口朝上，需防尘设计（仓壁+灯体间隙） | 转轴区域防尘 |

**对工程对接者的提示**：垂直顶出方向的最大新增工程量在**机身顶部堆叠重排**（灯体全藏 + 弹出高度预留），电路部分（升压/储能/触发）与弹出方式无关、维持 §2.1 拓扑不变；2×AA 供电定义不变（已确认）。

### 2.3 与整机时序的关系（两个关键衔接）

**（a）回电 3-8s 与拍摄节奏**：氙灯充电与拍摄是异步的——弹出即开始充电，充好即待命（指示灯亮），拍摄时即时放电。用户无感知等待的场景是"刚弹出就拍"（低概率）；连拍场景每张间隔 3-8s，与"认真拍照"的产品节奏（取景、构图、过片拨杆的仪式动作）天然兼容 [M]。

**（b）AF 时序在架构 B 下无冲突（重要说明）**：AF 验证报告（v03-af-lens §5 第 4 条）曾提示"AA 供电架构下氙灯充电与 AF 动作的电流脉冲叠加"风险——**该风险随电源架构 B 裁决（锂电主电 + AA 专供闪光灯）已消解**：AF/VCM 由主锂电供电，氙灯充电走 AA 独立回路，两路电气隔离（隔离成本 ¥1-2 已含在双仓电源 BOM 内 [M]），电流脉冲不存在叠加路径。此条写入本文档是为了让工程/ODM 对接者不再重复排查该风险。

### 3.3 ODM 对接接口（客供关键料模式）

供应链评估报告 R3 已裁决：**氙灯模组列为"客供关键料"自购**，不交给整机厂采购。执行含义：
- 我方掌握灯管/总成的供应商关系与价格，ODM 只负责结构集成与组装；
- 谈判时明确 ODM 的责任边界：总成到货检验标准、装配工艺、与整机的结构/电气接口（连接器、安装孔位）；
- 好处：避免 ODM 因"非主流料"加价或拒接，也避免供应主动权外流。

| **周期** | 询价 1-2 天 + 物流 3-5 天 + 搭板验证 3-5 天 ≈ **2 周内完成** |
| **验证内容** | ① 3V（2×AA 模拟电源）升压到 300V 可达性；② 充电时间实测（对标 3-8s 假设）；③ 触发可靠性（连闪 100 次无误触发/漏闪）；④ 灯管亮度体感（对标 GN10 预期） |
| **通过标准** | 充放电链路全通 + 充电时间 ≤8s + 连续 100 次闪光零失败 |
| **不过怎么办** | 充电超时 → 换更大感量升压变压器或调整电容容值（电路参数问题，不涉及供应）；触发不稳 → 换触发线圈供应商样品对比；**全面失败（<5% 概率 [L]）** → 触发 LED 备胎评估流程（见 §4.5），但按双先例背书，此阶段失败概率极低 |

### 阶段 1：模组集成询价 + 弹出结构手板（第 2-4 周）

| 项 | 内容 |
|---|---|
| **动作 A：模组集成询价** | 向 2 家发询价——向阳兴（Instax 组件 15 件套经验）+ 一次性相机 OEM（聚鹏城类）；询"弹出式氙灯总成"定制价、MOQ、交期；同时索取其现成组件的品质记录（Instax 组件为参照基准） |
| **动作 B：垂直顶出结构手板** | 3D 打印 + 钣金混合验证件（参照 Yashica 35MF 顶出机构 DFM，归档参照图 bromo/ref/yashica-35mf-flash-popup.jpg）：① 机械开关触发手感；② 弹簧顶出力度与弹出速度（导轨阻尼调校）；③ 到位卡扣锁定的"咔"声与锁定可靠性（1m 跌落模拟不掉出）；④ 回压收纳力与收纳到位锁定；⑤ 灯体仓位与 300V 节点的防护布局；**同步输出顶出机构的机身内部堆叠占位图（灯体全藏高度+弹簧空间）供整机线评审**（联动 vf-odm 报告 §3.2 顶部堆叠风险） |
| **花费** | 手板 ¥1-3 万 [M]（3D 打印+钣金快速件口径）；询价零成本 |
| **周期** | 询价往返 1-2 周；手板制作+评估 2-3 周 |
| **产出** | ① 两家模组厂书面报价（1k/10k/50k 三档）+ MOQ + 交期；② 手板手感评估报告（开关触发力/弹出速度/到位锁定"咔"声/回压收纳力的主观评分 + 改进项清单）；③ 顶出机构堆叠占位图（交整机线） |
| **通过标准** | 至少 1 家报价落在总成 ¥6-11@10k 区间内（±30% 容差进 RFQ 谈判）；手板开关-顶出-锁定-回纳动作链完整、无结构干涉、到位锁定可靠；堆叠占位图获整机线确认无硬冲突 |
| **不过怎么办** | 报价全部超区间 → 拆分采购（我方自购灯管+电容标准件，只委托结构集成，压掉模组厂加价）；手板手感不达标 → 迭代 1-2 轮（每轮 ¥0.5-1 万 [L]），顶出机构原理简单，风险在调校不在可行性；**堆叠硬冲突（灯体全藏高度与主板/锂电/取景器光路无法避让）** → 立即上报 Leader 召集整机线联合评审——冲突不可解时此为产品级决策（灯体尺寸缩减 / 局部外露 / 回退旋转式），不是氙灯线可单方面消化的 |

### 阶段 2：EVT 可靠性验证（第 2-4 月，与整机 EVT 并行）

| 项 | 内容 |
|---|---|
| **前置** | 阶段 1 选定的模组厂出工程样（含弹出结构）；与整机 EVT 样机集成 |
| **验证清单** | ① 回电时间实测（碱性/镍氢双电池矩阵，各 20 组）；② 闪光寿命（连续闪光 1 万次抽测光衰与漏闪率，外推 5 万次）；③ 跌落后功能（1m 跌落×3 方向，顶出机构锁定可靠、灯体无损——含弹出态与收纳态两种跌落姿态）；④ 高温环境（50°C 存放 2h 后充放电与顶出/回纳动作正常）；⑤ 充电指示灯阈值一致性（20 台样机）；⑥ 灯管批次一致性（跨行业料专项：2 个批次光谱/触发电压对比）；⑦ 顶出机构寿命（开关-顶出-回纳循环 ≥1 万次，锁定功能与弹出速度无衰减） |
| **通过标准（EVT 门禁之"氙灯打样通过"，建议量化口径见 §6 决策点 2）** | 回电 ≤8s（碱性）；1 万次闪光漏闪率 <0.5%；跌落后功能正常（允许重新弹出一次自检）；50°C 后功能正常；批次一致性在容差内 |
| **不过怎么办** | 逐项归因：回电超时→电路参数迭代（模组厂责任）；漏闪→换灯管供应商（双供应商策略激活）；跌落失效→弹出结构加强（治具修改，¥0.5-2 万 [L]）；**系统性失败（多项不达标且无法归因单一环节）** → 提交 Checkpoint 诊断，评估 LED 备胎启用条件（见 §4.5） |

### 阶段 3：DVT/PVT 与整机对接（第 5-9 月）

| 项 | 内容 |
|---|---|
| **动作** | 以"客供关键料"模式与整机厂对接：总成到货检验标准（IQC 规范）、装配 SOP、结构/电气接口冻结（连接器选型、安装孔位公差）、批量供货节奏（与整机排产对齐，按 1k/3k/5k 批次滚动） |
| **验证** | DVT：装配良率（目标 ≥98% [L]）；PVT：量产线节拍验证 + 抽检不良率（目标 <1% [L]） |
| **通过标准** | IQC/装配/量产三级指标全部达标，双供应商（灯管）体系就位 |
| **不过怎么办** | 装配良率低→与 ODM 联合工艺评审（公差链分析）；产能爬坡慢→激活第二模组集成厂（阶段 1 报价留档的备选） |

### 4.5 LED 备胎的启动条件（唯一启用场景，COA 已裁决）

**备胎定位**：LED 备胎（手机级双色温闪光模组，BOM ¥2-4 [H]）**仅限断供启用，明确排除降本切换**——即：只有当氙灯供应链出现"无法通过供应商切换/参数迭代解决的断供"（例如四大渠道同时枯竭，评估概率极低 [L]）或阶段 2 出现"系统性失败"时，才提交 Checkpoint 评估切换。**任何以"LED 更便宜/更省事"为由的切换提议都违反 COA 裁决，直接否决。**

切换预案（万一触发）：手机闪光灯模组是现成货架方案，切换周期 2-3 周 [M]，但会牺牲凝固感与仪式感叙事——产品侧需重新评估"弹出结构保留（弹 LED 灯头）还是取消"。
