# Bromo 

:::
Mountain Bromo，布罗莫火山。位于印度尼西亚爪哇岛，以令人惊叹的日出景色闻名。

溴化银（Silver Bromide, AgBr），胶片摄影的核心感光材料。“Bromo”正是溴的词根。
:::

Bromo是极印仿胶卷潮玩相机品类的第二款单品，目标定价为999-1499价格带。

首先回顾仿胶卷潮玩相机品类的产品定义原则：

**产品定义原则**

1.  一切设计取舍以"四大需求"为标尺，**为“让认真拍照这件事更值得、更好玩”服务**；
    
2.  竞争格局直接决定产品边界：**不堆参数、不拼便利、强化仪式感与情感密度**；
    
3.  **与同类潮玩的竞争是长期命题**，不是产品定义阶段能解决的，它关乎壁垒构建；
    
4.  **硬件不是壁垒**，但硬件是壁垒的载体：仪式感设计（机械感、触感、声音）让用户"愿意开始用"，是启动的第一步；
    
5.  **风格算法投入优先级高于硬件参数堆砌**：参数可以被抄，"味道"需要积累，且"味道"是品牌辨识度的核心；
    
6.  **产品定义要为壁垒留接口**：软件架构支持持续迭代（迭代速度壁垒）、内容运营预留社区与挑战功能（内容飞轮壁垒）、营销话术从产品发布即绑定品类定义（品类心智壁垒）；
    
7.  **接受没有单点护城河**：壁垒是复合优势的持续积累，产品定义的一切取舍都要服务于"跑得更快"而非"筑墙更高"。
    

**四大需求下对比AiKen与Bromo**

| **需求** | **AiKen** | **Bromo** |
| --- | --- | --- |
| **出片更好看** | 1/3英寸传感器、软件端滤镜 | **提升传感器至1/1.28英寸**、复用滤镜 |
| **玩法更好玩** | 软件端特效（漏光、暗角、相框） | 支持**疝气闪光灯**、**标准螺纹支持滤镜片等、**复用特效 |
| **拿出手更有面子** | 轻便便携、塑料材质、110形态 | **经典形态**、巴掌大小依旧便携、**增加金属部分提升质感** |
| **发社媒更出圈** | 软件端二创、一键分享 | 复用 |

**Bromo产品定义初级方向**

1.  硬件
    
    1.  采用经典形态，参考徕卡M系列、富士X系列、Yashika 35系列等；
        
    2.  保留旁轴光学取景，仅Y方向偏离；
        
    3.  增加弹出式疝气闪光灯 + 2节AA电池仓（通过2节AA电池充电）；
        
    4.  拨杆过片（真实物理结构带来阻尼+机械+声音）；
        
    5.  快门支持 M3x0.5锥形螺纹，支持个性化快门帽；
        
    6.  镜头通用螺纹支持滤镜片等（螺纹尺寸待定）；
        
2.  影像
    
    1.  考虑采用 1/1.28" 传感器；
        
    2.  支持自动对焦镜头，快门半按对焦+自动测光；
        
    3.  支持2~3段焦距选择（自拍「近」、人像「中」、风景「远」），镜头环支持旋转切换；
