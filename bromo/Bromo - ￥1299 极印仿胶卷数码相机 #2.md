# Bromo - ￥1299 极印仿胶卷数码相机 #2

#### 为什么做第二款

1.  品类阵列：一个价位是单品，两个价位是阵列雏形，拓宽覆盖市场；
    
2.  能力复利兑现：研发沉淀的能力（影像研发、软件研发、风格化及运营）开始跨产品复用，同时补其它二级能力（大底影像、高质感CMF、闪光灯、配件生态）；
    
3.  飞轮的第二组叶片：双产品飞轮是阵列级，共享声量、联合投放、内容密度翻倍；
    
4.  财务拐点：不再是“不考核利润”。控制投入，追求可接受财务。
    

#### Bromo

Bromo是极印仿胶卷潮玩相机品类的第二款单品，目标定价为￥**1299**价格带。

:::
Mountain Bromo，布罗莫火山。位于印度尼西亚爪哇岛，以令人惊叹的日出景色闻名。

溴化银（Silver Bromide, AgBr），胶片摄影的核心感光材料。“Bromo”正是溴的词根。
:::

首先回顾仿胶卷潮玩相机品类的**产品定义原则**：

1.  一切设计取舍以"四大需求"为标尺，**为“让认真拍照这件事更值得、更好玩”服务**；
    
2.  竞争格局直接决定产品边界：**不堆参数、不拼便利、强化仪式感与情感密度**；
    
3.  **与同类潮玩的竞争是长期命题**，不是产品定义阶段能解决的，它关乎壁垒构建；
    
4.  **硬件不是壁垒**，但硬件是壁垒的载体：仪式感设计（机械感、触感、声音）让用户"愿意开始用"，是启动的第一步；
    
5.  **风格算法投入优先级高于硬件参数堆砌**：参数可以被抄，"味道"需要积累，且"味道"是品牌辨识度的核心；
    
6.  **产品定义要为壁垒留接口**：软件架构支持持续迭代（迭代速度壁垒）、内容运营预留社区与挑战功能（内容飞轮壁垒）、营销话术从产品发布即绑定品类定义（品类心智壁垒）；
    
7.  **接受没有单点护城河**：壁垒是复合优势的持续积累，产品定义的一切取舍都要服务于"跑得更快"而非"筑墙更高"。

#### Bromo产品定义初级方向

1.  硬件
    
    1.  采用经典形态，参考徕卡M系列、富士X系列、Yashika 35系列等；
        
    2.  保留旁轴光学取景，仅Y方向偏离；
        
    3.  增加弹出式氙气闪光灯 + 2节AA电池仓（通过2节AA电池充电）；
        
    4.  拨杆过片（真实物理结构带来阻尼+机械+声音）；
        
    5.  快门支持 M3x0.5锥形螺纹，支持个性化快门帽；
        
    6.  镜头37mm通用螺纹支持滤镜片等（螺纹标准可变更，后期根据实际情况调整）；
        
    7.  冷靴接口；
        
2.  影像
    
    1.  考虑采用 1/1.28" 传感器；
        
    2.  支持自动对焦镜头，快门半按对焦+自动测光；

#### 核心卖点

1.  认真拍摄的仪式感
    
    1.  机械拨杆过片，每一次都是一次认真记录；
        
    2.  无屏幕旁轴取景，没有数字焦虑，享受拍摄的过程；
        
    3.  氙气闪光灯，强化仪式感，适用场景更广；
        
    4.  支持"即时冲扫"和"经典冲扫"（随机等待3-24小时）两种模式，找回选片的乐趣；
        
2.  通用接口支持个性化表达：
    
    1.  支持个性化配件安装在快门和冷靴上；
        
    2.  镜头支持通用螺纹，适用各种滤镜片，扩展玩法；
        
3.  胶片风格直出：
    
    1.  承袭所有风格滤镜，持续推新玩不停；
        
    2.  结合漏光、颗粒、暗角特效提供更多个性化玩法；
        
    3.  整卷统一应用，模拟胶卷的固定色调特性；
        
4.  数码内核的便捷性：
    
    1.  极速开机，抓住值得记录的每一瞬间；
        
    2.  半按自动对焦，自动曝光，自动EV补偿，0基础上手；
        
    3.  可随时选择出片风格并传图至手机端查看，免去真实胶卷的金钱和时间成本；
        
    4.  支持多张照片拼贴创作，适配社媒，直出即可分享；
