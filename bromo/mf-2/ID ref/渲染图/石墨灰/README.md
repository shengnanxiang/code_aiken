## 三、QA 方法与阈值（程序化，可复核）

- **轮廓 IoU**：生成图与彩色样图的物体掩膜 bbox 归一化后计算（strict 掩膜排除投影）
- **玻璃检测**：物体左上前区域的亮圆斑检测（亮度前 2% + 圆度 + 长宽比过滤）
- **CMF**：dark25 < #3c3c3c、light25 ≥ #888888（侧视图 ≥ #747474，受光面少的物理特性）、colorful < 5%
- **阈值校准依据**：用户认可的基准图对其底图 IoU=0.845——即用户可接受的保真度水平；立体图生成分布据此校准为 0.70
- 每张的完整 QA JSON 在同目录 `*_qa.json`；批量日志在 `concept-renderer_workspace\analysis\batch_log.txt`
