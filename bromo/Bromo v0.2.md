# Bromo v0.2

::: info
Mountain Bromo，布罗莫火山。位于印度尼西亚爪哇岛，以令人惊叹的日出景色闻名。

溴化银（Silver Bromide, AgBr），胶片摄影的核心感光材料。"Bromo"正是溴的词根。
:::

Bromo是极印仿胶卷潮玩相机品类的第二款单品，目标定价为999-1499价格带。

---

## 产品定义原则

1. 一切设计取舍以"四大需求"为标尺，**为"让认真拍照这件事更值得、更好玩"服务**；
2. 竞争格局直接决定产品边界：**不堆参数、不拼便利、强化仪式感与情感密度**；
3. **与同类潮玩的竞争是长期命题**，不是产品定义阶段能解决的，它关乎壁垒构建；
4. **硬件不是壁垒**，但硬件是壁垒的载体：仪式感设计（机械感、触感、声音）让用户"愿意开始用"，是启动的第一步；
5. **风格算法投入优先级高于硬件参数堆砌**：参数可以被抄，"味道"需要积累，且"味道"是品牌辨识度的核心；
6. **产品定义要为壁垒留接口**：软件架构支持持续迭代（迭代速度壁垒）、内容运营预留社区与挑战功能（内容飞轮壁垒）、营销话术从产品发布即绑定品类定义（品类心智壁垒）；
7. **接受没有单点护城河**：壁垒是复合优势的持续积累，产品定义的一切取舍都要服务于"跑得更快"而非"筑墙更高"。

## 四大需求下对比AiKen与Bromo

| **需求** | **AiKen** | **Bromo** |
| --- | --- | --- |
| **出片更好看** | 1/3英寸传感器、软件端滤镜 | **提升传感器至1/1.28英寸**、复用滤镜 |
| **玩法更好玩** | 软件端特效（漏光、暗角、相框） | 支持**氙气闪光灯**、**标准螺纹支持滤镜片等**、复用特效 |

| **发社媒更出圈** | 软件端二创、一键分享 | 复用 |

## Bromo产品定义方向

### 1. 硬件

1. 采用经典形态，参考徕卡M系列、富士X系列、Yashika 35系列等；
2. 保留旁轴光学取景，仅Y方向偏离；
3. 增加弹出式氙气闪光灯 + 2节AA电池仓（通过2节AA电池充电）；
4. 拨杆过片（真实物理结构带来阻尼+机械+声音）；
5. 快门支持M3x0.5锥形螺纹，支持个性化快门帽；
6. 镜头通用螺纹支持滤镜片等（螺纹尺寸待定）；
7. 镜头环支持三档焦距切换（详见「三档焦距方案」）；
8. 冷靴接口。

### 2. 影像

1. 考虑采用1/1.28"传感器；
2. 支持自动对焦镜头，快门半按对焦+自动测光；
3. 支持三档焦距选择（自拍「近」、标准「中」、人像「远」），镜头环支持旋转切换；
4. 档位3（人像/中）通过数字裁切模拟等效50mm，配合超分辨率算法补偿画质。

## 三档焦距方案（v0.2新增）

### 核心架构

**单Sensor + 单镜头模组 + 物理近拍机构 + 数字裁切**

### 三档详细定义

| 档位 | 名称 | 等效焦距 | 对焦距离 | 实现方式 | 适用场景 |
|------|------|---------|---------|---------|---------|
| **1** | 自拍/近 | 35mm | 0.3m ~ 0.5m | **物理**：镜头前组伸出 + 近拍镜片介入 | 自拍、特写、桌面美食 |
| **2** | 标准 | 35mm | 0.5m ~ ∞ | **物理**：镜头标准位置 | 日常随拍、风景、人文 |
| **3** | 人像/中 | 50mm | 0.5m ~ ∞（数字裁切） | **数字**：中心裁切 + 算法优化 | 人像、半身、背景虚化 |

### 档位1 vs 档位2 的物理区别

**档位2（标准）→ 档位1（自拍）时：**
- 镜头环旋转带动**凸轮机构**
- 镜头前组**向前伸出约2-3mm**
- 内置的**近拍镜片组**进入主光路
- 最近对焦距离从0.5m缩短到**0.3m**

**机械反馈：**
- 磁吸定位 + 弹簧钢珠 → 清晰的"咔嗒"档位感
- 镜头伸出时的阻尼感 → 类似老镜头的"拧出"手感

### 档位3的数字裁切

| 参数 | 数值 |
|------|------|
| Sensor原生分辨率 | 12MP（1/1.28"典型值） |
| 档位2输出 | 12MP全幅 |
| 档位3裁切后 | 约**5.8MP**（裁切比1.43x） |
| 档位3等效 | 50mm |

**5.8MP够用吗？**
- Instagram最大1080px宽 → 完全够用
- 小红书/微博 → 够用
- 打印4R（6×4英寸）→ 够用

### 算法补偿（档位3必备）

| 算法 | 作用 |
|------|------|
| **超分辨率（Super-Resolution）** | 将5.8MP插值到8-10MP，提升观感锐度 |
| **人像模式虚化** | 模拟50mm f/1.8的浅景深效果，掩盖裁切感 |
| **肤色优化** | 50mm人像档专用LUT，让肤色更讨喜 |
| **边缘锐化** | 适度提升中心锐度，补偿裁切损失 |

### 镜头环UX设计

**旋转方向（从正面看）：**

```
        人像/中（50mm）
              ↑
              |
    自拍/近 ←——●——→ 标准（35mm）
    （0.3m）   |
              |
           OFF（关机/镜头缩回）
```

**档位感设计：**

| 档位 | 机械反馈 | 视觉反馈 | 声音反馈 |
|------|---------|---------|---------|
| OFF → 标准 | 轻微阻力 + 咔嗒 | 镜头缓缓伸出 | 低沉"咔" |
| 标准 → 自拍 | 明显阻力 + 咔嗒 | 镜头再伸出2-3mm | 清脆"嗒" |
| 标准 → 人像 | 轻微阻力 + 咔嗒 | 屏幕显示50mm框线 | 低沉"咔" |

**图标标识（刻于镜头环侧面）：**

| 档位 | 图标 | 含义 |
|------|------|------|
| 自拍/近 | 👤 或  | 人物半身/自拍 |
| 标准 | 🌄 或  | 通用场景 |
| 人像/中 | 👥 或  | 人像/中景 |

### OFF档绑定设计

- **关机时**：镜头自动缩回OFF位置
- **开机后**：默认转到标准档（档位2）
- **实现方式**：凸轮+弹簧复位机构 + 霍尔传感器检测

## 光学取景器方案（v0.2新增）

### 问题背景

三档焦距下，旁轴光学取景器存在视差和裁切范围不可见的问题：

| 档位 | 实际成像区域 | 取景器看到的 | 问题 |
|------|-----------|-----------|------|
| 自拍/近（0.3m） | 广角35mm | 旁轴取景器固定视角 | **视差最大**——近距时旁轴偏移最显著 |
| 标准（0.5m~∞） | 广角35mm | 旁轴取景器固定视角 | 轻微视差，旁轴DNA |
| 人像/中（50mm裁切） | 中心裁切区域 | 旁轴取景器固定视角 | **构图偏差**——取景器显示全幅，实际只拍中心 |

### 解决方案：光学取景器 + 极简LED框线

**方案：保留旁轴光学取景器的仪式感，通过LED框线解决视差和裁切问题**

| 档位 | 取景器显示 | 视差处理 |
|------|-----------|---------|
| **档位1（自拍/近）** | 35mm全幅 + **LED修正中心点** | 近距视差最大，用中心点提示实际成像位置 |
| **档位2（标准）** | 35mm全幅（**纯光学，无额外标记**） | 轻微视差可接受，旁轴DNA |
| **档位3（人像/中）** | 35mm全幅 + **LED 50mm中心框线** | 提示裁切后的实际构图范围 |

**LED框线示意（档位3）：**

```
┌─────────────────────────┐
│  ○  ○  ○  ○  ○  ○  ○   │
│  ○                    ○ │
│  ○   ┌───────────┐    ○ │
│  ○   │           │    ○ │  ← 50mm框线（LED点亮）
│  ○   │   实际    │    ○ │
│  ○   │  成像区   │    ○ │
│  ○   │           │    ○ │
│  ○   └───────────┘    ○ │
│  ○                    ○ │
│  ○  ○  ○  ○  ○  ○  ○   │
└─────────────────────────┘
        光学取景器视野
```

**技术实现：**
- 光学取景器内部增加**LCD透明显示层**（类似单反的AF点显示）
- 不同档位时，LCD显示对应的框线/标记
- 成本增量：约¥8-15

## Sensor与镜头选型建议

### Sensor：1/1.28" 12MP

| 参数 | 建议值 |
|------|--------|
| 尺寸 | 1/1.28"（约9.8mm × 7.3mm） |
| 分辨率 | 12MP（4000 × 3000） |
| 像素尺寸 | 约1.4μm |
| 特性 | 支持相位对焦（PDAF）、HDR、4K视频 |

### 镜头模组

| 参数 | 建议值 |
|------|--------|
| 实际焦距 | 约5.4mm（等效35mm） |
| 光圈 | f/2.0 ~ f/2.4 |
| 结构 | 5片4组（含1片非球面） |
| 对焦 | 固定对焦（档位2/3）+ 近拍镜片位移（档位1） |
| 近拍镜片 | 附加1片平凹透镜，位移量约2-3mm |

## 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 档位3裁切后画质用户不满意 | 中 | 算法补偿 + 用户教育（50mm是"风格档"，不是"画质档"） |
| 近拍镜片位移机构可靠性 | 中 | 选用成熟凸轮方案，寿命测试≥10万次 |
| 三档机械结构增加厚度 | 中 | 优化凸轮曲线，控制增量≤2mm |
| 用户误操作（比如在档位1拍远景） | 低 | 取景器提示 + 软件自动提醒 |
