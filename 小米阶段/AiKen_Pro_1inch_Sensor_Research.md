## 二、镜头方案

### 2.1 1 英寸传感器的镜头特点

1 英寸传感器对角线约 16mm，相比当前 AiKen 的 SC1320CS（1/3.06英寸，对角线约 5.2mm），传感面积增大约 **8.8 倍**。这意味着：

- **等效焦距系数**：1英寸传感器的裁切系数约 2.7x（相对全画幅），即 10mm 实际焦距 ≈ 27mm 等效
- **镜头口径**：需更大通光孔径，镜头物理直径增加约 40-60%
- **法兰距**：1英寸传感器对镜头后组设计要求更高，但短法兰距仍可实现（如索尼 RX100 系列镜头组仅 25-30mm 厚）

### 2.2 可更换镜头方案

AiKen Pro 定位为**可更换镜头系统**，每颗镜头支持**单次自动对焦（AF-S）**和**手动对焦（MF）**两种模式：

- **AF-S（单次自动对焦）：** 半按快门触发对焦，合焦后锁定，全按拍摄。适合静态场景（人文、风景、静物）
- **MF（手动对焦）：** 转动镜头对焦环手动调节，机身通过震动反馈合焦提示。适合微距、低光、创意拍摄

镜头内置 VCM（音圈马达）或压电马达驱动对焦镜组，通过电子触点与机身通信。MF 采用 focus-by-wire（电子手动对焦）方案，转动对焦环产生电信号控制马达，降低机械复杂度同时保留手感。

| 参数 | 当前标准款 | Pro 可换镜头系统 |
|------|-----------|---------|
| 传感器 | SC1320CS 1/3.06" | LYT-900 1" |
| 对焦方式 | 固定焦距（泛焦） | AF-S + MF（每颗镜头内置马达） |
| 等效焦距 | 35mm（固定） | 35/50/24/鱼眼/微距（可换） |
| 光圈 | F2.2（固定） | F1.8-2.8（因镜头而异） |
| 镜片组 | 3P+1G | 5P+2G 或 6P+2G（含非球面，每颗独立设计） |
| 对焦马达 | 无 | VCM 或压电马达，行程 2-5mm |
| 光学厚度 | ~8mm | ~15-20mm（含对焦镜组行程） |
| 电子触点 | 无 | 6-8 触点（供电 + 对焦指令 + 光圈控制） |

#### 方案 B1：物理卡口式（类 Realme / Leica M）

```

│     AiKen Pro 机身           │
│  ┌─────────────────────┐    │
```

| 项目 | 详情 |

| 零售价 | 每颗附加镜头 ¥149-249 |

**优点：** 物理连接最稳定，对焦指令传输零延迟，无供电问题  
**缺点：** 需要卡口开模（模具费高），机身厚度增加 ~5-8mm，防尘防水设计复杂  
**成本增加：** 卡口模具 + 密封 + 触点 ~¥40-60/台  
**适合：** 追求画质极致、可接受体积略增的 Pro 定位

| 项目 | 详情 |
|------|------|
| 连接方式 | 磁吸环对位 + 弹簧触点供电/数据 |
| 数据传输 | 可选：MIPI 直连（低延迟）或无线近场传输（类 LaserLink） |
| 对焦驱动 | 镜头内置 VCM/压电马达，通过弹簧触点接收对焦指令 |

| 镜头类型 | 每颗镜头为独立模组（含镜头组 + VCM 马达 + 对焦环） |

| 零售价 | 每颗附加镜头模组 ¥149-299 |

**优点：** 用户体验最好（一吸即用），可扩展性最强，可做不同焦段镜头生态，AF-S/MF 全支持

**成本增加：** 磁吸组件 + 触点 + VCM 马达 ~¥50-80/台  
**适合：** 最符合 AiKen "潮玩" 定位，生态扩展性强

#### 方案 B3：磁吸式 + 独立 SoC（类追觅 AURORA）

| 项目 | 详情 |
|------|------|
| 连接方式 | 纯磁吸（物理对位），无电子触点 |

**对焦交互设计（无屏场景）：**
- **AF-S 模式：** 半按快门 → 镜头对焦马达驱动 → 合焦后机身短震动反馈 → 全按拍摄
- **MF 模式：** 转动对焦环 → 机身实时检测合焦状态 → 合焦时长震动提示（替代屏幕对焦确认）
- **模式切换：** 镜头侧面 AF/MF 拨杆，切换时机身短震动确认

## 四、技术风险与建议

### 4.1 主要风险

| 风险项 | 等级 | 说明 |
|--------|------|------|
| 1英寸传感器功耗 | 中 | LYT-900 22nm 已优化至可接受，但 AiKen 无屏设计散热有限 |
| 磁吸触点精度 | 中 | 需保证多次插拔后触点不磨损、不氧化 |
| 镜头模组小型化 | 中 | 1英寸传感器要求更大镜头口径，需光学设计团队攻关 |
| 供应链授权 | 低 | 磁吸传输协议可自研，不依赖小米 LaserLink |
| 防尘防水 | 中 | 磁吸接口缝隙需 IPX4 密封设计 |
| 成本控制 | 高 | 可换镜头版影像模组 BOM 增加约 260-430 元 + 磁吸/卡口组件 50-80 元，占比 ~25-35%，需定价策略覆盖 |
| 对焦马达可靠性 | 中 | VCM 音圈马达成熟但需验证多次磁吸插拔后触点供电稳定性；MF focus-by-wire 需调校手感 |

### 4.2 建议

1. **传感器选型：** 首选 LYT-900（低功耗+高画质），备选 SC5A5XS（全国产成本优势）
2. **镜头方案：** Pro 直接采用方案 B2 磁吸可换镜头系统，每颗镜头支持 AF-S + MF 双模式
3. **对焦系统：** VCM 音圈马达为主力方案（成熟、成本低），微距镜头采用压电马达（微步精度高）；MF 采用 focus-by-wire 电子手动对焦
4. **时间节奏：** 
   - 标准款已定义 SC1320CS → Pro 磁吸可换镜头版（T+12月），标配标头，后续逐步扩展镜头生态
5. **生态策略：** 首发 1 颗标头 + 1 颗人像，后续每季度推 1 颗新镜头，复用"风格解锁"任务系统（拍满36张解锁新镜头购买资格）
6. **传输协议：** 若选磁吸方案，建议自研短距无线传输（参考 UWB 或近红外），避免依赖第三方授权
7. **无屏对焦交互：** AF-S 合焦震动反馈 + MF 合焦长震动提示，替代屏幕对焦确认
