## 二、QA 结论（交叉制衡：cmf-texture-engineer 权威 QA + 渲染师视觉确认）

**总判定：4 张可用交付；open_hero（主推）与 c_hero（有投影版）为本批最优。**

| 检测项 | c_hero | c_hero_alt | open_hero | open_hero_alt |
|---|---|---|---|---|
| 俯侧视角特征 | ✓ | ✓ | ✓ | ✓ |
| 双圆件检出 | 单大圆（多解 A/B，见下） | 单大圆（同） | ✓ 双圆（偏移 0.012/r+5%） | ✓ circle1（r+1%） |
| 接地投影 | ✓ 弱（26%） | ✗（2%） | 极弱（10%） | 弱（13%） |
| 蒙皮占比 vs 基线 | -18% | -11% | -17% | -13%（视角改变合理范围） |
| 主色 hex 距离 | 浅 3-17 ✓ | 13-20 | 浅 3-4 优秀 | 8-28 |

圆件视觉确认（渲染师高分辨率放大转写）：close_hero 圆件视觉尺寸与 MASTER 同量级（暗玻璃心+亮环带结构一致），未见实放大漂移——采信工程师的解读 A（45° 椭圆投影，r 比增大 33-46% 恰为 1/cosθ 几何证据）+ B（同心环检测合并）。

## 三、已知偏差（如实标注）

1. **close 版圆件检测多解**：Hough 只检出单一大圆——解读 A 椭圆投影（最可能）/ B 检测合并 / C 实放大漂移（与 open 版 +1~5% 表现矛盾，概率最低）。渲染师视觉确认支持 A/B，判定通过
2. **构图投影变化**：obj AR 1.47-1.62（基线 1.69/1.93）、物体偏大偏左——侧转 45° 的预期投影效应，机位语言正确落地
3. **接地投影缺失（3/4 张）**：仅 c_hero 有可测投影（26%），其余 2-13%——"落地不浮空"目标**仅部分达成**，轻中度抠图感残留。改进路径：a) 后续重拍时 prompt 提高 contact shadow 权重；b) 程序化软投影叠加（cmf-texture-engineer 可提供，只加背景投影层，产品像素零改动，随时可做）
4. **深色区偏暗偏暖 17-28**：45° 机位下深色面受光减少+暖光的物理合理表现；观感上深色件比 MASTER 更沉
5. **细节未验证**：logo/缝线/按钮等超出转写分辨率，建议目检
6. **分辨率非 4K**：通道限制（见规格表）
