## 四、已知偏差（如实标注）

1. **小暗圆件 r 比差 -35%**（超 ±15% 带）：单个最小圆件（暗玻璃件）在方形版中略小于产品基线；主因是枪灰版式基准本身机位更远/圆件视觉更小（基线 0.38-0.49 vs 产品基线 0.216-0.339 的坐标系差异），属版式对齐的连带效应，如实标注不修
2. **分辨率 2048² 非 3840²**：wan2.7 带参考图时 API 上限 2048²（4K 仅纯文生图）。若需 3840²：后续可对交付版 Lanczos 上采样+锐化，或换 4K 通道（如 google 配额重置后走代理）
3. **光影变体说明**：alt 版为同 prompt 重采样（生成模型随机性带来的微差异），非独立光影设计
4. **细节未验证**：logo/缝线等细部超出转写分辨率，建议目检
