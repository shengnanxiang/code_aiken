# 新 ID 元素级「老登感」诊断报告

> 诊断对象：`cmf\new id close.png`（1810×978）+ `cmf\new id open.png`（1927×1018）——用户已定稿不改的新 ID（左侧圆形玻璃闪光灯组件 + 缩小 logo）。
> 方法：全程程序化读图（k-means 聚类 / Hough 圆检测 / 局部纹理方差 / 边缘曲率回归 / 分区亮度统计），无多模态、无生成、无臆断；全部证据与脚本存于 `元素诊断_evidence\`，可复核。
> 用途声明（按 11-06 指示）：**设计不改**。本报告回答"老登感来自哪些具体元素"，输出为**传播叙事规避参考**——物料拍摄与文案如何扬长避短，让同一台机器读出"经典"而非"过时"。
> 判读三档定义：**读老**（关联传统/父辈/办公器材的视觉语言）｜**读复古潮**（关联胶片复兴/Y2K/潮玩的正向复古语言）｜**中性**（无明确年龄指向）。

## 一、七维度元素诊断表

### 1. 配色体系 —— 判读：**读老（偏老，主因之一）**

**证据**（new id close 聚类，主体 10 类占比加权）：
- 米灰壳体族：#D3D1CE(3.1%) → #C6C3BF(5.5%) → #B9B5AF(3.4%)，全部 **S≤0.05、H 17-18（暖灰）**
- 深色族：#565554(2.6%) / #403F3F(2.5%)，**S≤0.02 的纯中性深灰**
- 全主体统计：**S_mean=0.056，彩色像素(S>0.15)仅 4.4%，鲜艳像素(S>0.35)仅 0.2%**——99.6% 的主体像素是灰/米灰系
- 色相集中度：非中性像素的 H 全部落在 15-18°（暖灰米），无任何第二色相点缀

**判读依据**：
- 全身低饱和 + 单色相 + 暖灰倾向，是 1980-2000 年办公器材（ThinkPad 前身、传真机、老式收音机）与"中年男士皮具"的典型色域；
- 潮玩/年轻向产品的高识别配色普遍依赖**第二色相点缀**（对比项目历史：panda-pink 有 S=57 的粉色块 10.3%、panda-gold 有 S=159 的橙金 11.1%、panda-navy 有 S=100+ 的深蓝——这些"曾读潮"的历史方向**全部带高饱和第二色**；而现 ID 彩色占比 4.4% vs panda-pink 31.8%+）；
- 五套候选 CMF 横评（程序化直读）：**石墨灰-v1（S_mean=0.026）与熊猫-v2（S=0.051）同属低饱和读老区**；岩石白-v1（S=0.087）略暖化但同族；灰绿-v1（S=0.106）因绿相稍解腻；**只有低奢蓝-v4（S=0.151，vivid 12.2%，海军蓝点缀）在数据上跳出读老区**——即"换 CMF 也难去老登"的大半原因在于候选盘子里 4/5 也是低饱和系；
- 用户自合成的 newid-低奢金-c：S=0.057、vivid 0.2%——依然低饱和（金色在图中呈哑光浅金 #CBC9C5 系而非亮金），说明用户自己的探索方向也在克制区。

**公允说明**：低饱和本身也是"高级感/克制成体"的语言（KEF、Leica mono 系列），它读老还是读高级，取决于形态与物料配合（见下）。**色彩不是唯一主因，但它是年龄语言的第一信号。**

### 2. 蒙皮占比与位置 —— 判读：**读老（强主因）**

**证据**：
- 深色蒙皮占主体面积 **24.9%（close）/ 28.2%（open）**，覆盖左侧整面（leather 掩膜 ASCII：x 左侧 1/3 整块 + 顶带左段）；
- 蒙皮纹理 Laplacian std=23.3 vs 壳体 8.3——高颗粒压花质感成立，是全机纹理最重的材质；
- 主体明度结构：左半 L=119 vs 右半 L=171，**左深右浅的强不对称**；底带下缘 L=125-139 拉暗整体。

**判读依据**：
- 深色大面积蒙皮 = 经典胶片机（禄莱/富士 GS）的直系语言，单独看是"复古相机感"的正资产；
- 但在**整体低饱和 + 无跳跃色**的配合下（维度 1），深色蒙皮把整机推向"父辈的皮套相机/男士公文包"联想——年轻人的参照系里，大面积深皮具=老；
- 28% 是"半台机器都是皮"的量级：蒙皮从点缀（潮）变成了主体（传统）。
- 对照历史"潮"向：panda 系列蒙皮均以浅色（cream/pink 底）+ 深色仅做小面积点缀，占比与明度都更轻。

### 3. 圆形玻璃闪光灯件 —— 判读：**中性偏读复古潮（新 ID 的正资产，公允结论）**

**证据**（Hough 圆 (873,489) r≈94 确认 + 区域统计）：
- 圆盘内 #4B4B4B、L=75、Lsd=12.7、tex=13.7——**暗底 + 低纹理 + 柔和径向亮度变化**（zoom ASCII：圆内从中心到边缘有 1→2→3 的缓变，无硬反光）；外环 #4F4F4F L=80 有圈状亮缘（26.9 方差的环带）= 嵌件台阶；
- 右侧还有一个次级圆件 (1141,406) r≈50：#8F8F8E L=143，中灰、带暗芯（zoom：中心 1-2 值暗核+亮环），疑似镜头窗/传感器件，与左圆件形成**一大一小双圆节奏**。

**判读依据**：
- 圆形光学件（取景器/闪光灯/测光窗）是胶片机最具共识的"真相机"符号，形态本身读**复古潮**（富士 X100/Twid 相机取景器、潮流卡片机都在用圆窗语言）；
- 暗色磨砂玻璃在深色蒙皮上呈现为"安静的深圆窗"，克制、有机械感，不老气；
- 若按 v2 反馈做成"较亮磨砂玻璃 + 闪光灯 glow"，会更接近年轻向的"电子感"，但**现 ID 的暗色版本同样成立**——它是新 ID 里相机感贡献最大的单一元素。
- 风险点仅在体量：r≈94px（直径约占机身高的 33%）偏大，"大圆窗"比"小圆窗"更庄严、更少俏皮。

### 4. logo 处理 —— 判读：**中性（偏正资产）**

**证据**：
- 缩小后的 logo 标记：(1345,630,41,24) 与 (1374,647,42,24) 两枚暗色小标（L=96-97，对局部对比 ≈75 灰度），合计约 85×55px 区域，位于右下角；
- 相对旧版（1373×826 图中 275×71 大标）：归一宽度从 0.20 缩到 0.047，**存在感降为约 1/4**；
- 明度对比温和（ΔL≈75，非纯黑）：低调丝印感。

**判读依据**：小 logo = 克制 = 高级感语言（对照 Leica/Teenage Engineering 的小标策略），**不读老**。年轻受众对"大 logo 印花"反而更敏感（联想到长辈的商务礼品）。缩小是正确方向。

### 5. 分色逻辑与缝线 —— 判读：**读老（中因）**

**证据**：
- 水平分件缝仅检出 2 条（y=205 顶缝 / y=703 底缝），缝线浅（L 降幅 <30）；
- 无竖向分色、无跳跃色分件；上下分色以"明度渐变"过渡（底带 L=189 vs 顶带 L=184，几乎同色系）；
- 底部大暗带 (741,674,855,100) aspect=8.55 是一条贯穿的深色底缘，让机器"下盘沉"。

**判读依据**：
- "上浅下深、缝线极浅、整体糊成一件"= 老家电/老音响的一体化壳语言；
- 年轻向复古潮需要**件件分明**（形体清单 §3 自己也指出"禄莱 A110 的机械感来自件件分明"）；缝线深度不足使三段结构读不出来，机器的"机构感"只能靠双圆件独撑；
- 但注意：这与"太圆润"是同一复合问题的两面（见维度 7）。

### 6. 材质观感（哑光-亮光平衡）—— 判读：**中性偏读老**

**证据**：
- 全主体镜面高光占比仅 **0.07%**（L>235）——**几乎全哑光**；
- 壳体 Lsd=17.3 的柔和明度渐变（大面柔光），无任何硬高光点；
- 玻璃圆件也无反光耀斑（Lsd=12.7 柔变）；
- 蒙皮高颗粒（tex 23.3）vs 壳体近光滑（8.3）形成哑光内部的材质对比。

**判读依据**：
- 全哑光 = 克制高级（studio product 的素皮语言），但也 = 静态、安静、无"电子产品的活力"；
- 年轻向产品普遍保留 1-2 个"活"的亮点（金属圈反光/玻璃耀斑/亮色按键），全哑光在年轻受众的联想里偏向"沉稳的中年选物"；
- 判为中性偏读老：单看材质是高级的，组合进低饱和体系后加重老登。

### 7. 整体轮廓与圆角 —— 判读：**读老（强主因，历史遗留）**

**证据**：
- 主体上边缘直线拟合残差范围 31px（resid_std=5.2px），顶部整段为**连续大弧过渡**，无可读平面段；
- body bbox 填充率 0.80、整体轮廓接近"鹅卵石"（body ASCII：连续圆角包络，左右两端大弧收尾）；
- 与 `ID形体建议清单.md` 既有反馈完全一致："全部大圆角过渡，关闭态呈鹅卵石……视觉上接近耳机充电盒/充电宝"。

**判读依据**：
- "鹅卵石 + 低饱和 + 深皮"三件套叠满时，读老的权重大幅上升：圆润本身是"温和、无害、家电感"，年轻受众把"无棱角"与"老一辈的圆润审美"关联（对照：年轻人追捧的复古潮玩普遍保留棱线/台阶/外露螺丝）；
- **这是 ID 结构推导的结果（用户已说明不改），且与"太圆润偏小米生态件"的历史反馈同源**——列为读老元素但明确：不可动、只能传播端规避。

## 三、传播叙事建议（原"修改菜单"，按设计不改的指示改写为扬长避短参考）

> 原则：同一台机器，**镜头、光线、构图与文案可以让它读"经典"，也可以让它读"过时"**。以下建议只动传播物料，不动产品。

### A. 拍摄角度与机位
1. **多用 3/4 俯视侧 45°（-hero angle-）**：让左侧深色蒙皮退为暗部背景、右侧米色壳与双圆件成为受光主体——规避"左深右浅不对称"读成"沉闷"，转读"层次"；
2. **双圆件特写必拍**：圆形玻璃件是全机最强"真相机"符号（维度 3 正资产），建议一张"大圆窗+小圆窗同框"的中景特写作为主打图之一；玻璃件上打一个柔和反光条（柔光箱条光），让磨砂玻璃"活"起来；
3. **低机位仰拍取顶缝**：把顶面分件缝与顶带弧度读出来，制造"件件分明"的机械感暗示（补偿维度 5 缝线浅的问题）；
4. **避免正面平拍 + 均匀布光**：这个角度会把"鹅卵石轮廓 + 全哑光 + 低饱和"三张读老牌同时打满（正是年轻人看到"老登感"的最可能视角）。

### B. 细节特写选择
1. **优选**：圆形玻璃件（配条光）、蒙皮压花微距（tex 23.3 的高颗粒质感是"用料"证明）、缩小 logo 丝印特写（低调=高级）、抽拉滑筒动作瞬间（核心卖点可视化）；
2. **规避**：整机正面素图、底缘深色带大特写（下盘沉感）、无参照物的大面积蒙皮平面图；
3. **对比物叙事**：拍摄时让产品与胶片机摆件/胶卷盒同框静物构图，把"复古"锚定在**胶片文化**（潮）而非**父辈用品**（老）——参照系决定年龄语言。

### C. 文案方向
1. **借"禄莱 A110 / 胶片机"的经典叙事**而非"商务/耐用"叙事——同一台深皮低饱和机器，讲"禄莱血统"读经典，讲"品质稳重"读老登；
2. **把"35-40+"定位转译为"胶片世代的第二台相机"**：不是给中年人的礼物，而是给玩过胶片的人的回归件——年龄语言从"使用者的年龄"切换为"审美谱系的年龄"；
3. **双圆件命名**：给圆形玻璃件一个有出处的名字（如取景窗/闪光灯模拟件的谱系典故），让符号被"读懂"而不是被"看到"；
4. **避免**的词：沉稳、大气、商务、经典耐用（这些词在年轻语境里全部加龄）；**推荐**的词：胶片、暗房、快门仪式、机械感、复刻、袖珍禄莱语汇。

### D. 一句话结论（主因/灵魂结构）

| 类别 | 元素 | 传播端对策 |
|---|---|---|
| **老登感主因**（传播需主动规避视角） | ① 全身低饱和单色系（4.4% 彩色）② 深色蒙皮 28% 占比 ③ 鹅卵石轮廓（大圆角无面） | 45° 俯侧机位 + 条光激活玻璃件 + 胶片文化锚定 |
| **复古灵魂**（传播端要放大的正资产） | ① 圆形玻璃双件（相机感最强符号）② 缩小 logo（克制高级）③ 蒙皮高颗粒质感（用料证明）④ 深皮+暖米的经典配色（讲对故事就是"禄莱血统"） | 特写 + 典故命名 + 经典谱系叙事 |

**核心判断**：这台机器的"老登感"不是某个元素坏了，而是**三个读老信号（低饱和/深皮占比/圆润）叠加、且缺少一个年轻化对冲信号**。传播物料无法改变产品本身，但通过机位、光线、参照系与叙事锚点，可以把同一组元素从"过时的深灰皮盒"重新框定为"胶片世代的袖珍经典"——后者正是 35-40+ 人群愿意买单、且不会吓退年轻同事的中间态。
