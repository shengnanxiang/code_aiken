# AiKen 定价敏感度测试（PSM）执行方案

> **文档性质**：研究执行方案（交给研究伙伴可直接执行）
> **方法**：Van Westendorp 价格敏感度测试（PSM）+ Gabor-Granger 阶梯收尾
> **决策问题**：AiKen 首发定价（499 / 599 / 699 三选一及版本策略）落在哪个点，心理可接受价格带在哪，不同分群的价格防线差多少
> **前置警告**：8 月内部调研的价格数据（399-499 条件性接受）已被内部样本污染，**本方案的第一原则是换池子重建数据**。本方案输出前，一切价格结论均为假设

---

## 一、为什么是 PSM + Gabor-Granger，而不是直接问"你愿意付多少"

- 直接询价得到的是谈判姿态（往低了报）或讨好姿态（往高了报），不是心理结构
- PSM 用四个"感受型"问题让受访者无意识标出自己的心理防线，交叉出四个关键点：PMC（临界便宜）/ PME（临界贵）/ OPP（阻力最小点）/ 可接受带（RAI）
- PSM 划"带"，Gabor-Granger 在带内选"点"（不同价位购买意愿 → 预期收入最大化的价位）
- 成本结构对拍：MPC 250 元、NRE 660 万、渠道费用约 25%——心理带与成本回收曲线的交集就是"溢价空间的量化表述"

## 二、刺激物控制清单（方案成败的第一关）

8 月访谈已证明：**受访者在不同材质、功能、"是否可重复使用"的理解下报的是不同产品的价**。所以本轮的铁律是"一个产品想象"：

| # | 控制项 | 要求 |
|---|---|---|
| 1 | 统一样机演示视频 | 30 秒上手演示：抽拉过片动作 + 声音（真实收音）+ 无屏幕取景 + 计数器跳变。**声音必须真实**——8 月访谈中机械手感是拉力核心，无声视频会系统性压低出价 |
| 2 | 统一样张集 | 8-12 张：人像（含肤色近景）×3、街景 ×2、暗光 ×2、聚会 ×2、打印成品 ×1。样张须为当前固件真实直出，**不得美化**（上市后差评会反噬测试结论） |
| 3 | 统一版本说明卡 | 一页说明：核心机制（36张/卷、拍完取出、冲扫二选一）、可重复使用（明确写出"无耗材成本"）、App 闭环、打印机联动。**"可重复使用"必须显式呈现**——8 月数据表明该认知使价格锚从 150-200 上移至 499 可接受 |
| 4 | 呈现顺序固定 | 问卷内：视频 → 样张 → 说明卡 → PSM 四问。**禁止先问价格再看产品** |
| 5 | 措辞统一 | 全程称"AiKen 复古胶卷相机"（或最终定名），不出现"小米""生态链""打印机品牌"等可能引入品牌锚的词 |

## 三、样本设计

| 维度 | 要求 | 理由 |
|---|---|---|
| 样本量 | **n ≥ 100**（PSM 推断级下限）；预算允许则 150 | n=10 时一个交点移动 10 个百分点，无意义 |
| 招募池 | **外部真实用户**：①小红书/社群公开招募 ②极印口袋打印机存量用户（私域触达）③大学生社群 | 存量用户是首发最可能转化的人群，也是"互相导流"论证的验证机会 |
| **排除条件** | 本公司及生态链公司员工、亲属；已深度参与 AiKen 项目的任何人员 | 内部池教训固化 |
| 筛选问卷 | 复用 55 人问卷的筛选逻辑：拍照频率、胶卷/CCD/拍立得接触史、"手机拍照太普通"共鸣度 | 保证与 8 月样本可比 |
| 配额分群 | 核心潮玩审美人群 ≥ 50%；打印生态存量用户 ≥ 25%；泛打卡人群 ≤ 25%。**分群配额必须记录** | 8 月访谈已显示仪式驱动型与务实型价格锚差 3-5 倍，混合样本的"平均价"会掩盖结构 |
| 年龄 | 18-35 岁为主（≥70%） | 目标人群定义；8 月内部样本 26-45 岁男性偏多，需纠偏 |

## 四、PSM 四问（核心模块措辞）

> 呈现位置：样机视频 + 样张 + 说明卡之后。提示语统一：
> "接下来几个问题和价格感受有关，没有正确答案，凭直觉回答即可。"

1. **[太贵]** 请问在什么价格下，您会觉得 AiKen **太贵了，不会购买**？
2. **[贵]** 请问在什么价格下，您会觉得 AiKen **有点贵，但还是会考虑购买**？
3. **[便宜]** 请问在什么价格下，您会觉得 AiKen **很便宜，物超所值**？
4. **[太便宜]** 请问在什么价格下，您会觉得 AiKen **便宜得让您怀疑它的质量**？

**作答形式**：开放式填空为主（保留原始分布），后台按 50 元档位归并。若担心开放填空中位数漂移，可用"滑条 + 参考31锚点区"混合，但**不得给任何竞品价格提示**。

**潮玩品类特别关注——"太便宜"曲线的社交解读**：买来聚会展示的产品，"太便宜"触发的可能不是质量怀疑而是**掉价感**。因此在四问之后追加一题：

> 5. **[掉价]** 请问在什么价格下，您会觉得拿 AiKen 出来拍照"不够有面子"？

此题结果不进 PSM 曲线，单独分析——它与"太便宜"曲线的分离度，就是"质量防线"与"面子防线"的距离，直接决定高质感版/联名款的定价天花板。

## 五、Gabor-Granger 阶梯（收尾模块）

PSM 四问 + 面子题之后，随机分组进入阶梯：

> "如果 AiKen 定价为 ___ 元，您购买的可能性是？"
> （1=肯定不买 2=可能不买 3=不确定 4=可能买 5=肯定买）

- 阶梯设计：起点随机（449 / 499 / 549 / 599 / 649 / 699 六点中随机起点），向上/向下阶梯各 2 步
- 分析口径：4+5 合并为"愿意购买"，计算各价位需求率与**预期收入指数**（价格 × 需求率，以最大值为 100）
- **分群输出**：核心潮玩 vs 存量打印用户 vs 泛打卡人群各画一条需求曲线——版本策略（主力款/联名款价差）的证据就在分群曲线的分离度里

## 六、问卷结构与防污染设计

```
S1 筛选（2 min）：身份排除 → 拍照行为 → 品类接触史 → 共鸣度
S2 刺激物（3 min）：视频 → 样张 → 说明卡（顺序固定，单页逐屏）
S3 认知检查（30 s）："这台相机拍完一张后能马上在相机上看吗？"（Y/N）
   ——答错者数据剔除：连产品机制都没理解的价格回答是噪声
S4 PSM 四问 + 面子题（2 min）
S5 Gabor-Granger 阶梯（1.5 min）
S6 分群变量（1 min）：年龄、性别、月可支配、设备持有、是否打印机用户
S7 开放题（可选）："什么情况下你会带它出门？"
```

**防污染三原则**：全程无竞品价格出现；无"小米/生态链"品牌词；S3 认知检查做数据清洗闸门。

## 七、分析模板

| 输出物 | 说明 |
|---|---|
| 四线累计曲线 | 太贵/贵从高价向低价累计；便宜/太便宜从低价向高价累计（**方向别画反**） |
| PMC = 太便宜×贵 交点；PME = 便宜×太贵 交点 | PMC-PME 之间为可接受带（RAI） |
| OPP = 太贵×太便宜 交点 | 阻力最小点，心理甜点参考 |
| 分群曲线 × 3 | 核心潮玩 / 打印存量 / 泛打卡 |
| 需求曲线 + 收入指数 | Gabor-Granger 输出 |
| **成本交集图（方案必做）** | X 轴价格、Y 轴双线：心理需求率曲线 + 成本回收线（NRE 660 万按预期销量分摊）。交集即"心理带内的生死销量" |

**读数纪律**：OPP 不是"建议定价"，是心理阻力参考；最终定价 = OPP 与收入指数峰值与成本交集三者的权衡，由产品决策会裁决，研究只出证据不出结论。

## 八、常见坑清单（执行前研究伙伴须逐条确认）

1. ❌ 先问价格再看产品 → 顺序锁死
2. ❌ 刺激物里出现"参考价 499"或任何数字 → 全文数字清洗
3. ❌ 内部员工顺手填一份凑数 → 排除条件写进招募链接筛选
4. ❌ 样张用精修图 → 上市后差评反噬
5. ❌ 混合样本算均价 → 分群配额强制记录
6. ❌ 把"太便宜"当质量问题解读 → 先看面子题分离度
7. ❌ 用 PSM 交点直接定定价 → 只出带，点由 G-G 与成本对拍收尾
8. ❌ 忽略 8 月教训：不统一"可重复使用"认知 → 说明卡显式呈现

## 九、交付物与时间线建议

- 问卷终稿（本方案 S1-S7 结构 + 措辞）→ 研究伙伴 2 天内回稿评审
- 预测试 n=10（外部小样本）→ 检查四问开放填空的分布与 S3 通过率
- 正式执行 1 周 → 报告 3 天内出
- 报告模板：四线图 + 分群曲线 + 需求曲线 + 成本交集图 + 一页结论（带内落点建议区间 + 风险声明）
