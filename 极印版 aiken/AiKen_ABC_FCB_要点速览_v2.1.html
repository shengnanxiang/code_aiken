AIKEN · 消费者行为学战略备忘录

ABC / FCB 要点速览v2 校准版 · 2026-10-20

AiKen = 极印自有品牌（汉图科技）的潮玩数码相机 · 标准版 ¥599 · 首批 ≤2000 台滚动补货 · 品牌资产优先（交付物是心智，不是利润）

主 Slogan：因为不知道，所以认真 情绪价值 = 设备仪式感 × 内容情感密度 × 认真度 —— 「认真」必须挂在「不知道」的产品机制后叙述，不可当独立功能点叫卖

1主心骨：贯穿所有决策的一段话

SPINE

AiKen 位于 FCB 感觉型象限（高介入 × 偏感性）：用户路径是 A(动心) → C(求证) → B(下单)——先被氛围感与「认真」身份叙事击中，再搜评测/比价/确认品牌可信，然后下单；买完还有购后第二循环（越用越爱：使用 → 满意成片 → 任务解锁 → 值得印的那几张变成实体照片），循环产出 UGC 反哺新用户的 A。

所有决策只需问一句：「这件事是在强化『心动』，还是在把用户推回『比参数、比价格』？」——前者对，后者错。

2两个假设的裁决

假设一：「ABC：先 A 再 C 后 B」

部分成立
  • A-C-B 非教科书标准层级（标准序列只有 C-A-B / C-B-A / A-B-C）
  • 但与 FCB 感觉型象限权威序列 Feel → Learn → Do 同构：先动心、再求证、后行动
  • 且不完整——购买后还有第二循环（B 主导反哺 A/C），风格解锁五任务即制度化的 B→A 强化设计

假设二：「FCB：高介入、偏感性」

部分成立
  • 偏感性成立（证据压倒性）；象限归属正确 = 感觉型
  • 介入度 = 象限内中低档（v2 上修约半档：限量小盘慢销 = 反冲动化设计；价格风险低 × 认知风险升 × 公司刻意放慢 三力对冲）
  • 人群分层：靶心偏感觉型 / 学生辐射群趋近反应型 / 存量打印机用户信任前置（介入度结构最好）

4四个维度：结论 / 该做什么 / 警惕什么

产品定义 POSITIONING

感性内核在品牌切换中零漂移——「竞争赛道不是影像能力（参数），而是情绪载体（风格）」，36 张 / 无屏 / 免对焦 / 冲扫等待四线文档完全一致。

该做什么

  • 设备仪式感四要素（机械感/触感/声音/姿态）转为可验收工程指标进 TR 评审
  • 「有命名的标志性直出色彩风格」是 SI/COA C 类必达（命名即色彩哲学，直出与冲洗共用同一哲学）
  • 新 Slogan「因为不知道，所以认真」按链路纪律落地：先「不知道」的机制，后「认真」的结果
  • 设计语言可延续到二代（品牌视觉资产，非一次性晒点）

警惕什么

  • 参数升级诱惑：任何升级必须落到可感知的 A 维度（更好看/更有面子/更出圈）
  • 仪式感通胀：同时放宽多个稀缺性设计（中途看片/缩短等待/降门槛）会稀释仪式感——每次放松做「情绪价值公式」评估
  • 「认真」当独立功能点叫卖（脱离「不知道」机制即空洞口号）

功能 PRODUCT

理性功能「不拖后腿」保底，竞争力在魅力型需求的密度，不在期望型参数（KANO 结论）。

该做什么

  • 三条理性底线为量产硬闸门：出片链路一次成功率 ≥99% · 真实场景盲拍满意率 ≥85-90% · 风格过「识货关」（胶片玩家盲评）
  • 联动按最新决策实现：统一 App「拍→冲→创→印」闭环，同一 App 同一账号（设备直连已取消）
  • KANO 反向验证四条用例进每版回归：无回看入口 / 无网络连接 / 36 张强制取出 / 无社区·云端·公开分享
  • 风格解锁五任务保持轻量门槛（「3 张 = 带出门随便拍几张就够」），「周末影记」留存设计不加重
  • 传输可靠性纪律：失败不删数据、断点续传、临界电量 5% 强制中止保护

警惕什么

  • 销量压力下「加个小屏幕回看」类提议——加屏 = 自我放逐到比参数战场，摧毁全部感性叙事（KANO 漏斗直接拒绝）
  • 品牌切换期为「建信任」加实用功能的冲动——先过 KANO 归类再评审
  • 已废弃的设备直连/印放旧功能回流（软件说明书已删除线处理）

定价 PRICING

三轨定价已锁定（SI/COA 受控页）：标准 ¥599（白牌天花板之上、日系入门之下的「新正牌着陆带」）· 联名/限定 699-799 · ¥499 仅作大促收官锚。

该做什么

  • 价格话术：「比 Flashback 便宜 200 块」+ 情绪消费预算类比（「一顿火锅」而非「半台相机」）
  • 剩余口径动作：上市策略旧数值更新（#5 定价待选项、#6 首发量 3000-5000 台 → 按 首批 ≤2000 台滚动补货）；B 端与历史物料排查「半价」残留
  • 打印套装（相机+打印机捆绑价）作为首发期核心 C 点论据：品牌信任物证 + 生态求证 + 存量用户钩子 + 购后第四环入口

警惕什么

  • 促销投放只用于转化末端，不用于获客前端——促销获来的是反应型用户，冲击好评率红线
  • 限量额度与渠道筛选必须绑定使用（限量对反应型客群是冲动放大器，加剧购后后悔）
  • 限量话术纪律：首批 2000 台售罄 70% 以上方可对外使用「限量」

营销策略 MARKETING

A 点是主战场（身份叙事种草），C 点是当前结构性短板——品牌切换后须补「品牌信任承接」；资源配置顺序 = Feel 先行、Learn 承接、Do 收口。

该做什么

  • 详情页顺序 = 路径顺序：第一屏 A（情绪钩子/「认真」叙事）→ C 段（3 步出片流程图 + 出品方信任陈述位 + 锚点表配感性翻译）→ 尾部 B
  • 品牌信任四件套外化：极印 = 打印机品类品牌（装机 20 万+）+ 正牌信号（自有研发团队/白名单渠道/公开售后承诺/有命名风格）
  • 达人钩子分层：胶片/复古垂类给「仪式感」钩子，泛生活方式给「认真」身份钩子；KOC 自发内容 ≥200 篇（无报备无返现，付费内容不污染自发口径）
  • 评测主动供给定调：风格盲评/冲扫等待体验/真实场景满意率，不接受跑分式画质对比
  • 风格 3/6/9 月上新配套召回推送 + 达人二创，把 OTA 运营成态度再唤醒事件
  • 存量用户转化漏斗：私域触达 A/B + 专属落地页 + 组合价 + 来源埋点（当前全线空白，P2 补齐）

警惕什么

  • 「即拍即打」话术不得再承诺「拍完直接打出」（实际为 App 闭环）——预期落差差评源；统一「值得印的才印」叙事
  • 锚点表参数行被直接截图使用（传输 40s、闪光灯短板两行须配感性翻译，战场拉到「拍完之后发生的事」）
  • 差评分类应对勿混淆：预期落差型（内容对冲）/ 品牌信任型（信任位 + 存量口碑外化）/ 批次质量型（公开声明+换新，拖不得）
