# 新品销量概率分布模型 · PM 使用手册（Playbook）

> **这是什么**：一份写给产品经理的操作手册——如何用「参照类 + Bass + 蒙特卡洛」方法为自己的新品生成销量概率分布，并用它做定价、预算、备货与 Checkpoint 决策。
> **配套工具**：《新品销量概率分布计算器_单机版.html》（单文件，双击即用，数据不出浏览器）
> **完整案例**：AiKen ¥699（本文所有示例数字来自该项目，v0.4 校准口径）
> **方法来源**：AiKen 项目 SI/COA 校准（2026-10）——CEO 要求「从三个点的预测转向概率分布经营」

## 一、为什么换方法：三个点 → 一条分布

传统的 Worst/Normal/Best 三档预测有一个根本问题：**它们是三个「猜测」，争论哪个对没有意义**。

概率分布方法把这件事变成可计算的：

```
传统：开会争论「到底卖 1.2 万还是 1.8 万」
新法：把 1.2 万和 1.8 万画在同一条曲线上，读出各自概率，
      讨论的是「我们怎么把曲线往右推」
```

三个直接好处：
1. **不吵架**——分歧被编码为分布宽度，而不是会议僵局
2. **可计算**——「预算加 50 万，P50 挪多少、达成 Best 的概率从 10% 提到 45%」，预算申请有了明码标价
3. **可验证**——上市后 30/90 天真实数据回来，分布收窄，预测质量看得见

**AiKen 实证**：用同套方法回测自家 S1 贴纸一体机——内部点预测 25,000 台位于事前分布 P92（模型当场就会预警「仅 8% 概率达成」），实际卖了约 10,000 台（P18）。点预测高估 2.5 倍；模型 P50=14,500，偏差 45%。分布把这两种可能都包含了。

## 二、模型怎么运作：3+1 框架

**一句话分工：参照类定参数，Bass 定形状，蒙特卡洛定分布，漏斗是杠杆。**

```
┌────────────┐   ┌───────────┐   ┌──────────────┐
│ 层1 RCF     │ → │ 层2 Bass  │ → │ 层3 蒙特卡洛  │ → 销量概率分布
│ 定参数      │   │ 定形状     │   │ 定分布        │
└────────────┘   └───────────┘   └──────────────┘
        杠杆层：运营动作 → 参数 → 分布右移
```

### 层 1 · RCF 参照类——参数从哪来

**做法**：找 3-5 个「同类 × 同价位带」的产品，用它们的真实销量给参数定区间。

- **m（市场潜力）**：品类累计销量上限。看比你贵一点的对标品卖了多少台，取一半到两倍做 P10-P90
  - AiKen 例：instax mini（¥599 同价位）定天花板、Flashback One35（¥749 直接对标）定存活基线 → m 的 P50 = 11 万台
- **q（口碑系数）**：社交传染强度。强社交货币品类 0.4-0.6；工具型产品 0.2-0.35
  - AiKen 例：CCD 潮、撕拉片炒价证明这个品类口碑传染强 → q = 0.42

**避坑**：
- ⚠️ 不要用不同价位带的产品定参数（DJI Pocket ¥3499 和 ¥699 相机的决策门槛完全不同）
- ⚠️ 内部预期不等于参照数据——先查对标品的电商销量再填数

### 层 2 · Bass 扩散——曲线长什么样

三个参数画一条 S 曲线：**m** = 曲线高度上限；**p** = 投放驱动的冷启动陡度；**q** = 口碑驱动的起飞斜率。

**关键机制**：p 不是手填的——由前 6 个月投流漏斗**反解**出来（这就是 3+1 里的「+1」）：

```
媒介预算 ÷ CPM = 曝光量 → × CTR = 点击量 → × CVR = 前6月销量
→ 反解出 p，钉进 Bass 曲线
```

**参数去哪找**：CPM/CTR/CVR 用自家最近投放数据（找市场部要，口径见附录作业单）。没有历史数据的新品类，锚一个「同品牌里最贵的产品」的实测值——高价品参数对低价品是保守的（AiKen 用 ¥1799 的 S1 参数锚 ¥699，正是这个逻辑）。

### 层 3 · 蒙特卡洛——不确定性有多大

参数不取单点，按层 1 区间随机抽 8000 组，各跑一条曲线 → 统计成分布。

**AiKen 结果示例**（¥699 口径）：

| 分位 | 首年销量 | 月均 | 含义 |
|---|---|---|---|
| P20 · Worst 锚 | 16,844 | ~1,404 | 跌破概率 20%（80% 置信守线）|
| P50 · Normal 锚 | 22,123 | ~1,844 | 最可能值，财务测算基准 |
| P90 · Best 锚 | 32,793 | ~2,733 | 冲刺带 |

### 杠杆层——每个动作推一个参数

| 运营动作 | 作用参数 | AiKen 实算效果 |
|---|---|---|
| 投放预算 ×1.5 | p ↑ | P50 22,123→31,419；P(≥Best) 10%→45% |
| KOC 种草密度 ↑ | q ↑ | 首年影响小、三年放大（时序依据：先投放后种草）|
| 品类破圈（新场景）| m ↑ | 三年上限抬高 |

**预算申请的新话术**：「这 50 万买到的是 P50 +3,000 台和达成 Best 概率 +15 个点」——把要钱变成买概率增量。

## 三、五步操作流程（对着工具做）

1. **填参照类先验**（工具左上区）：m 的 P10/P50/P90 + q。不确定就先填宽——分布宽是诚实，不是无能
2. **填漏斗参数**（左中区）：预算 / CPM / CTR / CVR。用附录作业单向市场部要数据
3. **填财务参数**（左下区）：定价 / BOM / ASP（不含税、扣渠道）/ 费用率 / 项目投入
4. **点运行** → 右侧出分布图 + 分位表 + 财务读数
5. **选锚并与财务表对齐**：三档锚 = P20/P50/P90（Worst 用 P20 = 80% 置信守线；想更宽可用 P10）——**锚位一旦定了，Finance 表、备货计划、Checkpoint 预警线全部用同一套**

**读数口诀**：
- 「P50 = X」→ 一半的可能性比 X 好
- 「P(≥Y) = Z%」→ 达成 Y 的概率是 Z
- 分位表黄色行 = 你的三档锚，直接复制进 Finance 表

## 四、四个使用场景

**场景 A · NPI 立项/定价决策**
跑 2-3 个价位对比（改定价和 ASP 重跑），看分布左移多少、单台净贡献升多少。AiKen 599→699→749 的对比就是这么做的：699 是财务甜点（单台贡献 +44%，P50 只降 0.4%——因为漏斗锚的是高价 S1 参数）。

**场景 B · 媒介预算申请**
改预算重跑，把「P50 变化 + 达成概率变化」写进申请。这是把预算讨论从「感觉」拉到「算术」的最快路径。

**场景 C · MOQ / 备货**
Normal 锚（P50）对应的首年量 ÷ 4 ≈ 首批备货参考（季度滚动）；Worst 锚 ÷ 4 = 压力测试下限。

**场景 D · 上市后 Checkpoint（30/90 天）**
首月实际销量进来后：月销 × 12 与 P50 对照，落在 P20-P80 之间 = 按计划走；跌破 P20 = 触发诊断（是 CTR 低还是 CVR 低还是品类假设错），不是降价。90 天再收一轮。

## 五、纪律与红线（从 AiKen 项目学到的）

1. **分布不消灭不确定性，它定价不确定性**——别把 P50 当承诺，把 P50 当最可能
2. **锚位一旦与财务对齐，不要单方面改**——P20 的 Worst 意味着 80% 置信守线，改锚要连着 Finance 表一起改
3. **价格不在 Checkpoint 响应选项里**——销量不佳时诊断漏斗哪一环（CPM/CTR/CVR/品类），降价会把分布整个搞坏且不可逆
4. **参照类要同价位带**——参数抄贵一档的产品，结论全错
5. **每个数字标来源**——评审被挑战时，「这个 CPM 是 S1 站内 45.2 实测」比「我觉得是 45」多活二十分钟

**税口径说明（重要）**：本方法统一采用「ASP 不含税 × BOM 含税」的保守配对——成本端含税、收入端不含税，等于给净贡献留了约 4pp 毛利率的安全垫（AiKen 699：BOM 250 含税，其不含税价为 221.24）。这是刻意的：财务建模宁可高估成本。若你的项目要求全不含税口径，BOM 需同时改为不含税价并重算，**但不要只改一半**（只改 BOM 不动 ASP 会虚高净贡献 28.7%）。
