## 二、为什么极印应该做：战略逻辑

1. **人群匹配**：蓝图核心人群「悦己氛围青年」明确写着「限定配色易转化」——这不是外部经验，是咨询公司给极印画像里自带的结论
2. **品牌跃迁需要证据**：潮玩相机=潮玩品类，潮玩品类的基本语法就是 CMF 矩阵（PopMart/instax 验证）；单 SKU 潮玩在消费者眼里是「电子产品」，多 SKU 限量才是「潮玩」
3. **ID 语言延续的兑现**：Sean 在校准会上要求「树立可延续的东西」——1.5 代 CMF 恰好是「设计语言延续」的最便宜实现：主板/结构/光学全部复用
4. **声量成本最低化**：Mini Evo 90 周年限量款规格零变化，产生的社媒讨论量远超硬件升级——CMF 是最便宜的内容引擎
5. **对冲 CEO 的观望策略**：CEO 说「先看市场反应再决定投入」——CMF 限量版的本质就是**用最小增量投入对市场反应做响应**：反应好→限量款放大（增量+复购）；反应一般→限量款维持声量（替代+溢价）；它本身就是「看反应再行动」的执行形态，而不是对观望的对立

## 四、销量预测分布（模型实算，200,000 次模拟）

基盘：AiKen ¥699 v0.4 口径（首年 P50=22,123 / P10=14,560 / P90=32,793）

| 指标 | P10 | P50 | P90 |
|---|---|---|---|
| **限量款合计销量**（2-3 款） | 5,252 | **8,511** | 13,319 |
| 品牌总盘增量（拉新+复购） | 2,263 | 4,083 | 6,851 |
| 总盘（基盘+增量） | 17,230 | 26,336 | 39,087 |
| 总盘提升幅度 | +12% | **+19%** | +26% |

财务（30% 费用率口径，单台限量净贡献 ~295 元 vs 标准款 102 元）：

| 指标 | P10 | P50 | P90 |
|---|---|---|---|
| 品牌净增贡献 | 126 万 | 206 万 | 326 万 |
| 增量 NRE | 184 万 | 263 万 | 356 万 |
| **净收益** | -176 万 | **-54 万** | +85 万 |
| P(净收益>0) | | **30%** | |

**诚实结论**：如果只算硬财务回报，CMF 项目在当前先验下大概率不回本（P=30%）——因为它的一半价值（替代+溢价）在贡献高毛利但被算作「本来也会卖的」，另一半（声量、品牌资产、人群圈层）不在损益表里。

**但换个算法（CEO 的框架）**：
1. 品牌总盘 +19%（P50）——对照 SI-1 品牌资产目标，这是声量与圈层渗透的直接放大
2. 单台净贡献 295 vs 102——限量款把「本来也会卖的那部分」的毛利抬了近 3 倍
3. Checkpoint 逻辑：CMF 是「看到市场反应后」的响应工具——30 天数据进来，限量款的机制参数（拉新 12% 中位）会被实测校准，分布收窄后再决定追加几款
