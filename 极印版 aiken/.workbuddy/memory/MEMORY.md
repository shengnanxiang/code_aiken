# 极印版 AiKen — 项目长期备忘

## AiKen CMF 硬约束（工艺规格，渲染与设计必须遵守）
1. 品牌 Logo（机侧面）为丝印工艺：平面油墨印在机壳上，禁止渲染成镂空/雕刻/立体效果；深色机身用浅色墨（如银灰）保证可读
2. 机身材质为塑料注塑，金属色用金属漆喷涂表达（微闪漆面、柔反射），禁止渲染成真金属（无拉丝、无阳极氧化、无镜面反射）
3. 前脸蒙皮不可用真皮贴皮（预算限制）；复古方向用深棕皮纹注塑（模具咬花）替代，也可考虑织物纹理
4. Logo 丝印颜色与蒙皮颜色保持一致（深色机身可例外用浅色墨保证可读）
5. 中间拉伸滑动件：纯色塑料件，禁止渐变/杂色（颜色可随方案定，可不选黑）
6. 机身壳、快门键、镜头外圈三件统一同色 = 该配色方案的「跳跃色」，用金属漆塑料质感处理
7. 蒙皮纹理定案：AiKen 蒙皮面积小，采用类织物细密纹理（编织感/织物纹），不模仿大面积相机蒙皮的皮纹/橘皮颗粒；橘皮纹理仅可用于金属漆面的质感表达，不用于蒙皮
8. 官方基底图：cmf/白棕-J.png（ID 团队出品，白棕配色，单视图、滑筒拉开镜头伸出状态）。后续所有改色/新配色一律以此图为基底换色，不再使用 AI 生成的形体作基底；改色时保留 ID 设计的结构（黑色内滑模块、镜头窗、开孔位），只换配色相关色面
9. 内滑模块颜色规则（2026-10-24 定）：跟随配色方案色（通常取蒙皮同色系），不固定为黑色；侧面开孔位为螺丝钉孔+Type-C 接口（非麦克风/挂绳），改色时保留原样
10. 产品尺寸硬规格（2026-10-24 定）：关闭态约 107×46×33mm，展开态约 130×46×33mm，重约 150g——比马克笔略长、掌心大小、比信用卡（85.6×54mm）长 1.5 倍的小物件。渲染时必须体现「小巧」：镜头圈直径仅约 18mm（小而精致）、机身修长扁平（长高比约 2.8:1）、场景中必须有尺寸参照物（信用卡/AirPods/手持），禁止渲染成全尺寸相机体量
11. 新基底图（2026-10-24 晚定）：id/aiken-open.png（展开）+ id/aiken-close.png（关闭），替代白棕-J 谱系
12. CMF 语言转向（2026-10-24 晚定）：KEF 同色系被用户评审否决（太圆润/太小米风/无机械质感，40 女性与 18-30 年轻人均无感），转向「机械潮玩」——收圆角、滑筒咬花+抽拉刻度、镜头圈台阶双环、快门圆柱凸台、分件线加深；模具未开、内部堆叠不动，形体可探索。形体建议见 cmf/ID形体建议清单.md；探索稿 cmf/机械感探索/（A机械胶卷/B苔原进化/C千禧潮玩 ×开合）
13. 千禧潮玩胜出（2026-10-24 定稿）：C 方向用户最满意；B 苔原因金属银滑筒被否。定版 id/aiken-millennial-open/close.png：①快门键为与机身近平的嵌入式银片（低凸，非高圆柱）②比例严格按 107/130×46×33 修长条形 ③机身必须一体化单体（禁「滑筒独立胶囊包裹机身」的分断处理），滑筒为右侧凹槽式滑道 ④滑筒上下两条交叉滚花带+中间白抽拉箭头刻度（样式源：id/aiken-millennial-ref.png 截图）⑤滑筒右侧面可见 USB-C+螺丝孔 ⑥滑筒面 logo 区保留横线切割+白色丝印 logo ⑦配色：奶油白机身 #f4efe6、雾紫织物蒙皮 #b3a4c6、雾紫滑筒 #9d8cb5、黑内化模块 #262626、银镜头外环+银低凸快门
