# 仿胶卷效果 · 功能 PRD

> 版本：v0.1（草案，待评审）
> 日期：2026-11-07
> 事实源：DeepSeek 对话截图 01–06、`AiKen_MessageHouse_极印版.md`、`极印App_IA.md`、策略文档 slide 5/18
> 定位：AiKen App「冲洗 / 出片」环节的效果规格，供设计、研发、印刷打样共用

---

## 1. 背景与目标

AiKen 是**无屏 + 36 张限额**的仿胶卷相机，主 Slogan 是「因为不知道，所以认真」。用户拍完看不到，**「冲洗」是唯一的揭晓时刻**——所以仿胶卷效果不是装饰，而是这个产品情绪价值的落点。

**目标**
- 让「冲洗」成为整条体验里最值得截图、最值得分享的一刻。
- 用「不可预知但有边界」的物理效果，支撑「认真拍」的心理机制。
- 效果要经得起胶片玩家审视，不能是「套个 LUT 就说是胶卷」。

**非目标**
- 不做又一个通用滤镜 App（DazzCam / NOMO / FIMO 已占据该位置）。
- 差异化不在「滤镜多」，而在**硬件约束（36 张 / 无屏 / 过卷）+ 一卷叙事 + 实体打印**。

---

## 2. 设计原则

1. **物理准确优先于炫技**：目标用户里有一批懂胶片的人，细节错了会被公开拆穿，反而伤品牌。
2. **不可预知，但有边界**：惊喜可以有，但不能毁掉用户唯一一张重要照片。
3. **效果服务于「认真」**：不是堆料，是让每一张「有来历」。
4. **一次成卷、效果锁定**：同一张照片每次打开必须一样，不能「刷新一次变一个样」。
5. **印刷友好**：最终要打在相纸上，屏幕好看不等于纸上好看。

## 3. 事实核对：DeepSeek 的说法准不准

| # | DeepSeek 说法 | 判定 | 说明与修正 |
|---|---|---|---|
| 1 | 暗房红灯亮起、胶卷在显影液里慢慢浮现轮廓 | ⚠️ **概念混淆** | 红灯（安全灯）是黑白**印相/放大**用的，因为相纸对红光不敏感；**胶卷显影在全黑罐里进行，看不到**。应改成「相纸在显影盘里浮现」或泛指「暗房仪式」，不要写「胶卷在显影液里浮现」 |
| 2 | 漏光不是均匀分布，每张都加会假 | ✅ **准确** | 漏光来自机身缝隙/片门，方向性强、集中在某一边缘 |
| 3 | 漏光应是小概率（1% / 每卷 2–4 张） | ✅ **方向对，数值需统一** | 图 01 说 1%、图 03 说 2–4 张/卷（约 8–17%），两者不一致，需在 §5 定死概率模型 |
| 4 | 暗角是渐变柔和、有颗粒，不是死黑硬边 | ✅ **准确** | 硬黑边框是 toy camera / 劣质滤镜的特征，不是真实镜头暗角 |
| 5 | 暗角最暗处叠颗粒，ISO 越高噪点越重 | ✅ **准确** | 欠曝区域与高感胶片颗粒都更明显 |
| 6 | Kodak 漏光暖橘、Fuji 偏青绿、黑白白光/黑边 | ⚠️ **部分不准** | 彩色负片（C-41）都有**橙色色罩**，白光穿过片基后普遍呈**暖橙/红黄**，与品牌无关。品牌差异体现在**整体调色**（Kodak 偏暖黄、Fuji 偏青绿），不是漏光色。黑白/反转片漏光偏白或黑边——这部分是对的。**按品牌区分漏光色是设计选择，不是物理事实**，若坚持要差异化，应在文档里注明「设计约定」 |
| 7 | 首尾张最容易漏光 | ✅ **大体准确** | 装卷/卸卷时片头、片尾暴露在光下，最易雾化 |
| 8 | 提前取出 → 胶卷曝光 → 夸张漏光/划痕 | ✅ **合理** | 中途打开后盖会雾化胶片，叙事成立 |
| 9 | 相册「底片」模式、重力感应反转 | ✅ **合理** | 负片反转是真实概念；重力感应需防误触 |
| 10 | 一卷成片 / 接触印相（Contact Sheet） | ✅ **准确** | 接触印相就是把底片直接压在相纸上曝光，得到缩略正片 |
| 11 | 一卷 **24 张** | ❌ **与产品不符** | AiKen 规格是 **36 张**。另：110 胶卷历史上是 **12/24 张**，36 是 135（35mm）的数字——「110 形态 + 36 张」本身就是混血，见 §12 的叙事风险 |
| 12 | 「玩 CCD/老胶片机的年轻人最上头」 | ⚠️ **未验证** | 属于营销假设，PRD 里不作为事实引用，只作为设计动机 |

**一句话结论**：产品直觉很好，物理细节有两处硬伤（暗房红灯、漏光按品牌变色），数值口径不统一，另有几个关键效果漏了（见 §4.6–4.9）。

## 4. 效果清单与规格

### 4.1 胶片类型（Film Stock）——打包「一整套物理特性」

用户选的不是「一个调色」，而是**色彩 + 颗粒 + 对比 + 漏光基调 + 光晕**的整包。

| 胶片类型（建议命名） | 色彩倾向 | 颗粒 | 对比 | 漏光基调 | 备注 |
|---|---|---|---|---|---|
| 金 200（Kodak Gold 风格） | 暖黄橙，肤色偏暖 | 中 | 低–中 | 暖橙 | 最「大众记忆」的一支，建议默认 |
| 绿调 200（Fuji C200 风格） | 青绿、阴影偏冷 | 细 | 中 | 暖橙（物理） | 整体偏青，与金 200 形成冷暖对照 |
| 黑白 400（HP5 / Tri-X 风格） | 黑白 | 粗 | 高 | 白光 / 黑边 | 漏光逻辑与彩色不同 |
| 夜钨 800（Cinestill 800T 风格） | 钨丝灯冷调 | 粗 | 中 | 橙红 | **强光晕（halation）**，夜景杀手锏 |
| 过期卷（Expired） | 偏色、低饱和 | 粗 | 低 | 不定 | P2，作为彩蛋 |

> **命名纪律**：不要直接使用 Kodak / Fuji 商标做功能名，改用「金 200 / 绿调 200 / 黑白 400 / 夜钨 800」这类致敬式命名，规避商标风险（见 §12）。

### 4.2 暗角（Vignetting）

- 非线性渐变，四角不完全对称（更真实），**禁止死黑硬边**。
- 最暗处叠一层弱颗粒，与全局颗粒同源、不重复计算。
- 与 ISO / 曝光联动：欠曝越重，暗角越深、颗粒越明显。
- 强度默认「中」，可调轻/中/重。

### 4.3 漏光（Light Leak）

| 参数 | 规格 |
|---|---|
| 触发概率 | 单帧独立概率 p≈6%，36 张期望约 2.2 张；每卷上限 4–6 张 |
| 方向 | 左上 / 右上 / 左下 / 右下 / 整边，随机 |
| 颜色 | 彩色负片默认暖橙/红黄（物理基准）；品牌差异化作为设计层 |
| 强度 | 轻 / 中 / 重，默认中 |
| 位置约束 | **默认只作用于画面边缘**，不覆盖主体面部（见 §7） |
| 首尾张特权 | 第 1 张、第 36 张概率提升至 60–80%（或强制），形成「仪式感闭环」 |
| 提前取出惩罚 | 未拍完提前取出 → 该卷已拍照片边缘强漏光 + 划痕（「曝光」叙事） |

### 4.4 颗粒（Grain）

- 随 ISO 增大、随欠曝加重；暗部比亮部明显。
- 与暗角/漏光叠加时共用一张噪声图，避免「脏上加脏」。

### 4.5 划痕 / 灰尘（Scratches & Dust）

- 低概率（≤5%），细线/白点，**不遮挡主体**。
- 更多出现在「提前取出」惩罚场景，正常卷里克制出现。

### 4.6 光晕（Halation）——**补充，DeepSeek 漏掉的关键项**

- 强光源、高光边缘出现**红/橙色柔光晕**，是胶片最容易被一眼认出的特征。
- 夜景、逆光、灯泡场景最明显；「夜钨 800」拉满。
- 这是「这不是滤镜、是真胶片」最有说服力的证据之一，建议 P0。

### 4.7 片边 / 齿孔 / 帧号（Film Rebate）——**补充**

- 帧号（1–36）、批次字、齿孔、DX 码，作为可开关的「胶片边框」，默认开。
- **一致性提醒**：AiKen 是 110 形态，110 是**单孔/帧 + 纸背**；若照搬 35mm 双排齿孔会与硬件故事打架。建议做 **110 风格边框**，或明确声明是「致敬式边框」。
- 这是分享截图里辨识度最高的元素，建议 P1。

### 4.8 底片模式（Negative View）

- 反转色彩：彩色负片呈橙色底，黑白为负像。
- 重力感应反转**默认关闭**，改为长按切换，防误触。
- 定位为「炫技/分享」功能，P1。

### 4.9 日期戳（Date Stamp）

- 橙红 LED 数字，右下角，字体带轻微发光；**默认关**（与产品策略一致）。
- 真实 Point & Shoot 的经典细节，成本低、辨识度高，P1。

### 4.10 进阶效果（后续 / P2）

| 效果 | 说明 | 优先级 |
|---|---|---|
| 双重曝光 | 同帧叠加两次拍摄，创意向 | P2 |
| 过期胶卷 | 低对比、偏色、粗颗粒 | P2 |
| 推拉冲洗 | 欠曝 + 延长显影 → 高对比、粗颗粒 | P2 |
| 交叉冲洗 | 药水错配 → 强烈偏色 | P2 |

> 首发不要上这些，避免「效果多到像滤镜 App」，也避免教育成本。

## 5. 概率与随机模型

**卷长**：**36 张**（对齐产品规格；110 历史为 12/24，见 §12）。

**确定性要求（硬性）**
- 每卷生成一个 `roll_seed`；每帧效果参数 = f(roll_seed, frame_index)。
- 拍摄时锁定，冲洗时揭示——**同一张照片永远同一结果**。
- 相机侧把「是否提前取出」「帧序」「卷 seed」写入元数据，App 侧据此复现。

**建议概率表（初值，待用研校准）**

| 事件 | 概率 | 上限 |
|---|---|---|
| 单帧漏光 | 6% | 每卷 ≤6 张 |
| 划痕/灰尘 | 3% | 每卷 ≤4 张 |
| 首帧 / 末帧漏光 | 60–80% | 各 1 张 |
| 提前取出惩罚 | 触发即 100% | 已拍全部帧强效果 |
| 光晕 | 场景驱动（有强光源才触发） | 不设概率 |

**边界**：单卷「明显效果」总数建议 ≤8 张，避免「整卷都毁了」的观感。

## 6. 触发时机：机内 vs App

| 效果 | 应用位置 | 理由 |
|---|---|---|
| 基础 LUT / 暗角 / 颗粒 / 光晕 | **机内直出** | 保住「直出成片」的产品承诺 |
| 漏光 / 划痕 / 首尾张 / 提前取出惩罚 | **App 冲洗时应用** | 无屏 → 冲洗是唯一揭晓点；效果需要「等出来」 |
| 底片模式 / 日期戳 / 边框 | App 展示层 | 非破坏性，可开关 |

**必须解决**：机内渲染与 App 渲染的**色彩管理一致性**——否则「相机直出」和「App 冲洗」两张图颜色对不上，会被用户发现。

## 7. 用户控制与安全阀（最高优先级）

随机效果最大的风险是**毁掉用户唯一一张重要照片**。必须给出口：

1. **保真模式（Clean）**：全局关闭随机事件，只保留 LUT/暗角/颗粒。
2. **效果强度滑杆**：轻 / 中 / 重，默认中。
3. **单张「重洗」**：每卷限 1–2 次，可换一组随机结果（保留「仪式」但给后悔药）。
4. **非破坏性**：原图永远保留，效果可关。
5. **主体保护**：默认漏光/划痕只作用于边缘，不覆盖人脸（可通过轻量人脸/主体检测或固定安全区）。

> 没有这五条，`因为不知道所以认真` 会变成 `因为随机所以翻车`。

## 8. 冲洗体验（动画与声音）

- **暗房意象**：红光、显影盘、相纸轮廓浮现（**注意：这是印相环节，不是胶卷显影**）。
- 白噪音 / 液体声，音量默认低。
- 时长：即时模式（数秒）与经典模式（3–24h 随机）并存。
- 可跳过、可后台、可关闭动效（无障碍）。
- 建议在「浮现」过程中**逐张揭晓**，而不是一次性全出——把惊喜拉长。

---

## 9. 分享与社交

- **一卷成片**：36 张冲洗完自动生成复古排版长图 / 可左右滑动的 H5。
- **Contact Sheet**：接触印相风格缩略图总览，适合发「这一卷」。
- 单张分享保留边框、帧号、日期戳（可开关）。
- 分享图不二次压缩效果，保证「所见即所发」。

---

## 10. 印刷适配

- 屏幕色域（sRGB/Display P3）≠ 相纸色域，漏光/光晕在纸上容易「发闷」。
- 必须**打样校准**，并提供「印刷优化」开关（适当提亮暗部、降低过饱和）。
- 无边距打印会裁切边框/齿孔 → 预留安全区，或提供「满版/留白」两种版式。

## 12. 风险与边界

| 风险 | 说明 | 应对 |
|---|---|---|
| **随机毁片** | 最重要的一张被漏光/划痕破坏 | §7 安全阀；默认边缘化；重洗 |
| **胶片玩家挑错** | 暗房红灯、漏光按品牌变色、110 vs 36 | 修正文案；漏光色注明「设计约定」；叙事用「110 形态灵感」而非「复刻 110」 |
| **110 与 36 的矛盾** | 110 历史是 12/24 张，36 是 135 的数字 | 产品已定 36；对外避免精确复刻承诺，强调「形态灵感」 |
| **商标风险** | 直接用 Kodak / Fuji 命名 | 改致敬式命名；如需真名需授权 |
| **同质化** | 与 DazzCam/NOMO/FIMO 拉不开差距 | 强化「一卷 / 冲洗 / 打印」的硬件叙事，弱化「滤镜选择器」 |
| **性能** | 多层叠加（颗粒+漏光+光晕+边框） | 预合成、GPU 渲染、低端机降级 |
| **机内/App 色差** | 直出与冲洗两张图不一致 | 统一色彩管线，建立 LUT 单一真源 |
