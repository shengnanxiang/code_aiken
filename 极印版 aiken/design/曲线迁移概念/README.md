# 曲线迁移概念（task-curve-transfer 交付）

> 需求原话："我觉得这个方向挺有意思。能不能尝试把把左边机身上的曲线处理应用到右边壳子上。然后左边维持原来aiken open这个图里的蒙皮？cmf的话，整体参考石墨灰-v1文档。"
> 生成日期：2026-10-27 · 生成工具：DashScope wan2.7-image（2K）· MASTER 参考图：`design/aiken close.png`

## 一、需求解读（详见 reading_notes.md）

1. **曲线处理**（来自 concept 0 左侧参考机）：大尺度缓弧形面层分割——曲面分件线/蒙皮边界曲线语言，以明暗渐变带呈现，非刚性直线
2. **迁移目标**：AiKen 右壳（当前为平面直边语言）
3. **左壳**：维持 aiken open 原蒙皮结构（蒙皮+光面壳），不引入曲线
4. **CMF**：石墨灰-v1 体系——同色系深浅渐变（中石墨灰 #55555A 主体 / 银灰高光 #8A8C8E / 深炭灰下部 #454546 / 近黑前条镜头圈 #202120 / 深炭灰颗粒蒙皮 #3A3A3C），无跳跃色

## 二、方案矩阵（5 变体，两种蒙皮解读）

> **字面解读**：左壳保留原深橄榄绿蒙皮（variantA/B_greenleather）
> **默认解读**：蒙皮随整机 CMF 切换为石墨体系深炭灰（variantA/B/C 原三张）

## 三、已知偏差（诚实标注，AI 生图常见）

1. **构图/角度未严格复刻 MASTER**：生成图为 2048×2048 方画幅，产品在画面中占比明显大于原 aiken close（1373×826 横幅）；视角与原片的一致性**无法在本成员的 ASCII 转写分辨率下严格验证**，需人工目检确认形体未漂移
2. **变体 C 的凹槽走向**：prompt 描述为斜向流线，生成结果读起来更接近**竖直平行条纹**——与上一轮竖纹探索的方向意外接近，反而构成"曲线↔竖纹"谱系的中点；若用户要的是明确斜向，需重生成
3. **细节不可验证**：按钮/转盘/logo/胶片仓缝等细部、蒙皮颗粒纹理，超出 ASCII 转写分辨率，未验证；左壳"蒙皮 vs 光面"的材质区分从明暗布局看成立（左侧深色带），纹理细节需目检
4. **红线遵守**：三图的外轮廓均为圆角矩形机身（无结构性改动的迹象），但**形体保真的最终确认需人工目检**（本成员读图通道受限，已用像素转写做了能做的部分）
5. **绿蒙皮版特有**：A 图右半有约 7% 绿色像素（判断为左壳绿蒙皮的反射光/环境光沾染到右侧曲面，非蒙皮错位）；两图绿区实测均色 #4a533a-#50593d，比原蒙皮 #55603f 略暗 1-2 个灰阶，属光照差异范围；绿蒙皮与石墨灰机身的搭配协调性（撞色是否好看）属审美判断，留待用户目检
