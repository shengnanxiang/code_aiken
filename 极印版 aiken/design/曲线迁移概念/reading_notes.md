## 1. concept 0 里"左边""右边"各是什么？

**左侧对象**（x≈27..240，占图 48%）与**右侧对象**（x≈240..430）是**两台深蓝色产品、背面视角、并排紧贴**，中间以深色接触阴影相连（连通域分割为单一连通体，中部 x≈224-252 有最暗的接触带）。

- **左侧**：整体偏暗（#2d4f87 / #355792 / #213c71，多组深蓝），面部亮度不均匀，有复杂明暗结构
- **右侧**：整体偏亮（#4c6498 / #8fa9d3 顶板、#27457a 主体），面色更干净，**右端有一条清晰的竖直亮带+平行窄条结构**（x≈412 附近 `++##` 与 `##` 平行成对，纵贯上下，顶端有深色圆点/竖条组合特征）
- **对比**：右边整体高亮偏亮约 10-20 灰阶；两对象非同一台相机的两个部件，是两台并排产品（或同一产品的两种状态/两种方案并排）

**置信度：高**（色彩统计+分割+亮度分布三重证据一致）

## 2. "左边机身上的曲线处理"是什么？

左侧对象的面部存在**一组大尺度、低对比度的明暗渐变结构**：亮度字符画显示其面部由宽阔的波浪形明暗区构成（如 `==+++***####` → `***####%%%` 的渐变带），从上到下多次"亮→暗→亮"转换，转换带呈**宽缓的斜向/弧形走向**；色彩字符画显示亮区（B 亮蓝）与暗区（b 深蓝）之间的**分界不是直线，而是缓的曲线族**——最典型的是从中上部向左下、以及从左中向右下的两组缓弧，暗区呈"包裹"亮区的形态。

这与经典胶片相机的**曲面分割线/腰线弧**（curved surface break / waistline）特征吻合：面与面之间以曲线转折过渡，形成雕塑感的体积表达，而不是刚性直线分件。

**解读候选（几何细节需用户/Leader 拍板，见"存疑上报"节）**：
- 候选 A（最可能）：**蒙皮边缘曲线 / 曲面分件线**——左壳上有一块以曲线为边界的区域（蒙皮或色块），其边界呈连续弧线而非直线，是"曲线处理"的主体
- 候选 B：**腰线/棱线弧度**——整机腰线为一道下凹或上拱的弧线，而非水平直线
- 候选 C：**多曲线组合**——A+B 同时存在（转写中左对象下部确实有第二组弧形带）

**置信度：中**（大结构可确认是"曲线化的面层分割"，但 448×224 分辨率下无法分辨是缝线级曲线还是整面弧面转折）

## 3. "右边壳子"当前形态与左边差异

右侧对象（右壳）当前面部**没有**左侧那种大尺度曲线明暗结构：面色均匀（#27457a 单色占优），仅有的结构特征是**右端竖直亮带 + 平行窄竖条 + 顶部小圆点**（x≈412 `++##`/`##` 平行对，y 顶部 `#`）——更接近"光滑面板 + 竖直装饰线/边框线"的语言。右壳顶板更亮（#8fa9d3），暗示顶面有独立的浅色板。

即：**右壳是"平面直边语言"，左壳是"曲面曲线语言"**——这正是用户要求迁移的内容。

**置信度：高**

## 4. aiken open 蒙皮 / "左边维持原蒙皮"

- **右前壳/右侧面**：**浅米色壳面**（#c6c1b9 / #d8d3cd / #c4bfb7），有斜向高光扫过（`sssss→++++` 渐变）

## 7. 存疑上报（需 Leader/用户拍板）

1. **"曲线处理"的具体几何**：候选 A（蒙皮边缘曲线/曲面分件线）vs B（腰线弧度）vs C（组合）。字符画可确认"曲线化面层分割"的性质，但无法分辨缝线细节。**建议**：默认按 A 为主、B 为辅理解（与 ID 形体建议清单"让顶面/侧面出现可读的'面'"的机械感方向一致），在概念图中以"右壳出现曲线边界的大面分割"表达。
2. **"应用到右边壳子上"的右侧形态**：右壳背面/侧面是否也要保留右端的竖直亮带结构（当前转写显示的窄竖条）？默认不保留（那是当前状态的一部分，曲线迁移后应被曲线语言替换），但可出一个保留竖带的对照变体。
3. **两条需求叠加后的左右不对称**：左壳原蒙皮（深绿+米色）+ 右壳曲线 + 整机石墨灰 CMF——蒙皮色是否也应转为石墨灰体系（深炭灰蒙皮）？石墨灰-v1 图中蒙皮位置是深炭灰。**默认理解：整机 CMF 统一切石墨灰，即左壳为"深炭灰蒙皮 + 浅银灰壳体"，右壳为"浅银灰/炭灰壳体 + 曲线分割"**。此理解与"整体参考石墨灰-v1"的"整体"二字吻合。
