## 会议背景

AiKen产品与汉图CEO（Sean）及极印总经理（顾佳思）针对新硬件项目（原小米合作转向自研的“转极印”产品）进行 SI/COA（战略意图/关键成功因素）对齐。

会议核心目的是重新定义项目的战略定位，从单纯的“盈利导向”转变为“品牌投资与能力建设”，并确立以 **599元** 为定价基准、构建 C 端潮玩业务飞轮的执行路径。

同时，讨论了基于现有 Perella 打印机用户基础的“贴纸服务”MVP 方案，旨在通过低门槛服务培育市场，最终转化为硬件销售。

## 项目战略意图与 COA 重构

- **战略定位转变**
    
    - **从盈利到品牌投资**：明确该项目在单独财务维度上难以实现高额利润，其核心价值在于改变极印品牌“仅做照片打印机/口袋桌面”的固有形象，向“潮玩/潮流”品牌转型 。
        
    - **市场竞争机会**：国内暂无直接竞品进入，富士虽重叠但非直接竞争，白牌知名度低。极印有机会通过认真做产品占领用户心智，区别于杂牌 。
        
    - **团队能力沉淀**：项目旨在锻炼团队在 C 端潮玩打法上的营销、运营及产品能力，而不仅是硬件制造 。
        
- **关键成功因素（COA）梳理**
    
    - **S (Strategy/Strategic Intent)**：视频能力、闪光灯等硬件定义已定，无需讨论；营收贡献不作为强考核指标 。
        
    - **O (Operation/Objective)**：
        
        - **时间目标**：争取 Q2（6月）上市，瞄准 618 节点，目前存在约一个月延误风险 。
            
        - **定价策略**：暂定 **599元**。避免低价导致比价人群涌入，损害品牌形象；也不追求极高溢价，保持适中 。
            
        - **首批投产**：建议首批 **3,000台**（MOQ），后续根据市场反应每三个月调整一次订货节奏，以缓解供应链对小批量的顾虑 。
            
    - **C (Capability/Cost)**：
        
        - **财务底线**：将原 Normal 场景调整为 Worst 场景，设定亏损红线；Best 场景按 Normal 的 3 倍估算 。
            
        - **沉没成本处理**：10月前的小米阶段投入视为沉没成本，不计入本项目后续开支预算 。
            
        - **产品体验要求**：
            
            - **标志性元素**：建立可延续的滤镜风格和 ID 设计语言，即使无二代计划也要预留延续性 。
                
            - **快速响应**：强调快速开机和“泛焦碎肉白”效果，抓住瞬间拍摄体验 。
                
            - **验证机制**：建立上市后 30天、90天的 Milestone Checkpoint，追踪品牌效果并调整动作 。
                

## 财务模型与销量预测逻辑

- **财务测算调整**
    
    - **销量假设**：
        
        - **Worst**：月销 ~500台（原 Normal 值），作为底线 。
            
        - **Normal**：月销 ~1,000台（基于 MOQ 3,000台/季度倒推） 。
            
        - **Best**：月销 ~3,000台（Normal 的 3 倍） 。
            
    - **毛利预估**：Normal 场景下毛利约 **0.88**，Worst 场景下 **0.05**，Best 场景下 **4.41** 。
        
    - **费用修正**：原按 2% 计算的销售费用偏低，需与市场部（方明/Maggie）重新对齐，预计会有上调；返修率费用可适当下调 。
        
- **概率分布模型理念**
    
    - **拒绝单一 ROI 视角**：不只看最大概率点的 ROI，而是建立从最低到最高销量的正态分布模型 。
        
    - **提升高销量概率**：所有运营动作（如投放、体验优化）的目标是将销量分布曲线向右推移，即提高卖出 10万台甚至 100万台的概率，哪怕该概率初始仅为 1% 。
        

## 业务飞轮与体验闭环设计

- **构建 C 端业务飞轮**
    
    - **飞轮起点**：极致用户体验（让用户觉得 599元花得值）→ 产生声量与口碑 → 带动销量增长 → 获得更多资源投入体验与营销 。
        
    - **拒绝反向操作**：严禁通过降价、牺牲体验或不投放来换取短期销量，这会破坏飞轮启动 。
        
    - **流量转化逻辑**：若目标年销 10万台，转化率 5%，则需 200万点击，进而推导需 4,000万曝光量，据此计算营销预算 。
        
- **体验闭环与 Design for Share**
    
    - **情绪价值交付**：产品设计需包含让用户能“怼回去”质疑者（如“为什么买这个不如手机”）的经典案例和标志性滤镜 。
        
    - **UGC/PGC 运营**：
        
        - 建立官方平台或社区，鼓励用户投稿高质量照片。
            
        - 通过奖励机制获取照片使用权，并在平台展示，降低其他用户的学习门槛，提供“我也能拍出这样照片”的代入感 。
            
    - **一键分享打通**：实现从拍摄、编辑到一键发朋友圈/小红书的路径打通，满足用户“装到了”的社交需求 。
        

## “贴纸服务” MVP 方案探讨

- **业务洞察**
    
    - **痛点**：Perella 打印机非刚需，用户购买决策成本高；但用户对高品质贴纸有需求 。
        
    - **策略**：先提供低门槛的“贴纸制作+邮寄”服务，培养用户习惯和审美，待频次提高后自然转化为硬件购买 。
        
- **执行方案**
    
    - **MVP 形态**：开发微信小程序/H5，用户上传照片即可在线编辑、生成 Project，填写地址并支付（如 10元）后，后台接单打印并快递发货 。
        
    - **运营模式**：
        
        - **初期自营**：招募少量外包人员或使用内部机器搭建小型“贴纸农场”，跑通流程 。
            
        - **后期加盟**：开放给淘宝店主或线下渠道，提供专属二维码链接，形成分布式生产网络 。
            
    - **优势**：利用中国物流低成本优势，且在微信/抖音生态内完成闭环，优于跳转淘宝的体验 。
        
    - **推广路径**：先在极印 APP 内向现有打印机用户推送，验证需求后再扩大获客 。
        

## 关键决策与共识

- **项目立项标准与财务视角**
    
    确立该项目为“品牌投资型”而非单纯“利润型”项目。财务测算不再仅关注单一 ROI，而是建立销量概率分布模型，核心目标是通过运营动作提升高销量（如 10万台+）发生的概率。允许项目在初期出现亏损（Worst 场景），只要亏损在可控红线内，且能带来品牌资产和用户心智的提升。沉没成本（10月前投入）不计入后续预算考核。
    
- **定价与首批生产策略**
    
    产品定价暂定为 **599元**，以维持品牌调性并预留营销空间。首批生产数量定为 **3,000台**（MOQ），采取小批量、多批次（每三个月一次）的订货策略，以平衡供应链压力与市场不确定性。销售费用预算需重新评估，原 2% 的比例被认为不足，需与市场部对齐后调整。
    
- **体验闭环与运营重点**
    
    产品开发需聚焦“标志性滤镜”和“ID 设计语言”的延续性，确保快速开机和即时成像体验。运营层面需构建“Design for Share”闭环，打通一键分享至社交媒体的路径，并建立 UGC 内容池，通过官方精选和展示降低用户创作门槛，增强用户粘性和传播力。
    
- **“贴纸服务” MVP 推进**
    
    同意启动“贴纸制作服务”的 MVP 测试。由盛楠翔牵头，利用现有 Perella 设备和少量人力搭建最小可行性流程（小程序上传-支付-打印-邮寄）。顾佳思协调资源支持，初期在极印 APP 私域流量中测试，验证用户需求后再考虑规模化或加盟模式。此服务旨在作为硬件销售的转化漏斗前端。

> ###### AI洞察
> 
> - **战略转型的阵痛与机遇**：从 ToB/代工思维转向 ToC 品牌思维，团队面临的最大挑战不是产品定义，而是“业务飞轮”的构建能力。盛楠翔提出的“概率分布模型”实质上是将不确定性管理纳入战略核心，这是一种更成熟的创业心态。
>     
> - **服务先行策略的潜力**：“贴纸服务”MVP 是一个典型的“剃须刀-刀片”模式的变体（先卖服务/刀片，后卖机器/剃须刀手柄）。它巧妙地规避了硬件高昂的首次决策门槛，利用低频高质的服务建立信任和高频互动，为硬件转化铺设了极佳的温床。
>     
> - **数据背后的用户心理**：顾佳思提到的 Perella 双十一爆单证实了“价格敏感度”在特定情感价值产品面前是弹性的。用户愿意为“情绪价值”和“社交货币”支付溢价，这为 599 元定价提供了坚实的市场佐证，关键在于如何通过运营将这种潜在需求显性化。
