## 用户需求

基于极印 App 的 13 张界面截图，先把现有功能做分析归类，再搭建整个 App 的目标态 Information Architecture（信息架构）。要求：

- 从截图出发，逐屏梳理并归类现有功能，识别孤儿功能与缺失环节；
- 诊断当前「素材/功能轴」IA 的结构性缺陷（与已收敛的设计方向对照）；
- 搭建目标态 IA：创作首屏（免费获客 + 一键出片）+ 产品空间（按类、空间内可切设备）+ 我的；
- IA 须同步承接已收敛的 Creator×Jester 视觉方向、「数字全免费、实体收费」策略与品牌飞轮；
- 产出一份可直接用于团队评审与后续高保真设计的 IA 文档。

## 范围与边界

- 输入：13 张截图（n02–n08、s01–s05、d01）+ 23 页策略文档，无 App 源码；
- 输出：markdown 形式的 IA 文档，非代码、非高保真原型；
- 不含具体视觉稿、不含实现步骤；视觉仅给到原则级基调。

- 不依赖任何代码框架；内容为信息架构、导航模型与功能映射，可直接被设计/产品评审与后续高保真工具消费。

## 实施方法

1. **功能归类（证据驱动）**：以 13 张截图为唯一事实源，按「全局 chrome / 各 tab / 子流程 / 模态」逐屏列出功能，再重映射到三大域——创作、产品、我的。特别标注孤儿功能（如「我的音频」无 tab 归属）与策略承诺但未实现的环节（暗房/冲洗/二创/任务解锁）。
2. **当前 IA 诊断**：对照已收敛方向，指出 tab 轴为「素材/功能」而非「产品」、产品仅存在于模态、AiKen 无位置、四种版式语言不统一、约束以提示文字而非流程呈现。
3. **目标态 IA 树**：以「创作（默认首屏·免登录·一键出片）/ 产品（品类空间·空间内可切设备）/ 我的」为一级，向下展开到二级能力与内容池。
4. **导航与 tab 模型**：底栏收敛为 3 个一级入口；设备切换升级为产品空间内的一级动作，不再藏于顶栏「去连接」；未连设备时首屏即创作流。
5. **策略落点**：在 IA 中标明免费内容池（滤镜/模板/贴纸/AI写真）与实体收费边界（相纸/打印/硬件/礼盒）的位置，以及「用户作品即传播脸」的飞轮路径。

## 实施注意

- 所有结论必须可追溯到具体截图编号，避免主观臆断；
- 保留「现状 vs 目标态」对照，便于评审时说明改动的必要性；
- 文档内 IA 树用 Mermaid 表达，确保可被后续工具解析。

## 设计架构：极印 App 目标态 IA

信息架构以「**产品轴 + 创作轴**」替代现状的「素材轴」。底栏收敛为 3 个一级入口，设备切换作为产品空间内的一级动作。以下内容为 IA 结构（框架无关，React/shadcn 仅作组件体系占位）。

```mermaid
graph TD
  A[极印 App] --> B[创作 · 默认首屏 · 免登录]
  A --> C[产品 · 品类空间 · 空间内可切设备]
  A --> D[我的]
  B --> B1[免费内容流: 滤镜/模板/贴纸/AI写真]
  B --> B2[一键出片 Hook]
  B --> B3[引导连接设备]
  C --> C1[照片打印机]
  C --> C2[照片切割一体机]
  C --> C3[仿胶卷潮玩相机 AiKen]
  C1 --> C1a[Jester 偏版式: 卷36格母题/秩序]
  C3 --> C3a[拍 → 暗房 → 出片 → 分享 → 打印]
  D --> D1[账户/订单] D2[耗材/会员]
```

### 导航与 Tab 模型

- 底栏一级：**创作 / 产品 / 我的**（由现状 5 tab 收敛，解决维度混杂）。
- 顶栏：产品空间内显示设备切换器；未连设备时创作首屏仍可用。
- 空间内语气分区（Creator×Jester）：相机空间动效重（冲洗/揭晓/盲盒），打印机空间版式重（卷 36 格母题）。

### 视觉基调（原则级，具体色值待定）

- 基底中性、产品无关（暖白/黑/灰），能托住任意产品；
- 暖橙为唯一高光，仅在高光时刻出现；
- 无品牌角色，性格靠风格/动效/排版/文案表达。
